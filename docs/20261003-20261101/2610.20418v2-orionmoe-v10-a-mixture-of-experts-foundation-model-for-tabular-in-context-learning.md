## 摘要
表格基础模型能够通过从带标签的支持表中预测未见观测来实现上下文学习，而无需进行任务特定的参数更新。尽管近期取得了进展，但大多数现有方法依赖稠密架构，对不同特征和数据集应用相同的变换。我们提出 OrionMoE-Small-v1.0，这是一种紧凑的表格基础模型，将分布感知表示与以数据集为条件的稀疏混合专家计算相结合。OrionMoE-Small 构建于双轴 Transformer 架构之上，通过由单个单元格表示和更广泛的数据集上下文共同指导的路由决策来选择性地激活专家。该设计能够在异构表格问题之间自适应分配计算，同时保留跨任务共享的计算路径。该模型完全在由结构化因果先验生成的合成分类任务上进行预训练，并在不进行基于梯度的适应的情况下执行下游预测。在多个表格基准上的实验表明，该模型相较于规模大得多的基础模型具有有竞争力的性能，尤其在小上下文和高维数据集上结果突出。进一步分析显示，该模型在类别不平衡下具有较好的相对性能，并凸显了特征组合的重要性。

## Abstract
Tabular foundation models enable in-context learning by predicting unseen observations from a labeled support table without task-specific parameter updates. Despite recent advances, most existing approaches rely on dense architectures that apply the same transformations across features and datasets. We introduce OrionMoE-Small-v1.0, a compact tabular foundation model that combines distribution-aware representations with dataset-conditioned sparse mixture-of-experts computation. Built on a dual-axis transformer architecture, OrionMoE-Small selectively activates experts with routing decisions informed by both individual cell representations and the broader dataset context. This design enables adaptive allocation of computation across heterogeneous tabular problems while retaining a shared computational pathway across tasks. The model is pretrained entirely on synthetic classification tasks generated from a structured causal prior and performs downstream prediction without gradient-based adaptation. Experiments across multiple tabular benchmarks demonstrate competitive performance against substantially larger foundation models, with particularly strong results on small-context and high-dimensional datasets. Further analysis reveals favorable relative performance under class imbalance and highlights the importance of feature composition.
