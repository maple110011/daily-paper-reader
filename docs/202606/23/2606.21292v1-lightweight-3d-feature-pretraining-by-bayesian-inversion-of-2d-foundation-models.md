## 摘要
我们提出Casper3D，一种轻量级概率框架，用于将带噪声的多视图2D基础模型嵌入转换为潜在3D语义表示。我们将视图级语义特征建模为底层3D语义状态的带噪声观测，并通过一种基于集合的变分模型推断该状态，该模型在多视图推理中结合了相对位姿。Casper3D通过从新视角预测保留的语义观测进行训练，同时保持与视觉和文本语义空间对齐，以支持开放词汇的3D理解。该框架与骨干网络无关，适用于语言对齐和自监督嵌入。实验表明，Casper3D比简单的多视图池化产生更稳定的3D语义，尤其是在模糊和带噪声的设置中。

## Abstract
We present Casper3D, a lightweight probabilistic framework for converting noisy multi-view 2D foundation-model embeddings into a latent 3D semantic representation. We model view-level semantic features as noisy observations of an underlying 3D semantic state and infer this state with a set-based variational model that incorporates relative pose during multi-view reasoning. Casper3D is trained by predicting held-out semantic observations from novel viewpoints, while remaining aligned with visual and text semantic spaces for open-vocabulary 3D understanding. The framework is backbone-agnostic and applies to both language-aligned and self-supervised embeddings. Experiments show that Casper3D produces more stable 3D semantics than simple multi-view pooling, especially in ambiguous and noisy settings.

### 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：如何从多视图2D基础模型（如CLIP、DINO）的噪声、视角依赖的特征中，恢复出稳定、视角不变的3D语义表示。
- **背景**：当前方法多采用“提升-聚合”策略（如平均池化），将2D特征直接投影到3D点云上。但这些确定性聚合方式假设3D特征就是2D观测的加权平均，忽略了观测噪声、视角变化和不确定性。物理世界中的语义是视角不变的（一个点的桌子属性不因相机位置而变），而2D特征是受视角影响的有噪声测量。论文将问题形式化为一个贝叶斯逆问题：从多个有噪声的观测中推断潜在的3D语义状态。

### 2. 方法论：核心思想、关键技术细节

- **核心思想**：将3D特征提升视为贝叶斯逆问题。对每个3D点 \(p_i\)，假设存在一个未观测的潜在语义变量 \(z_i \in \mathbb{R}^d\)。每个2D观测 \(x_{ij}\)（来自相机位姿 \(T_j\)）是 \(z_i\) 的视角条件噪声版本：\(x_{ij} \sim p_\theta(x|z_i, T_j)\)。目标是推断后验分布 \(p(z_i | \mathcal{C}_i)\)，其中 \(\mathcal{C}_i = \{(x_{ij}, T_j)\}\) 是上下文观测集合。
- **关键技术**：
  - **变分推断**：由于后验难解，引入轻量级编码器 \(q_\phi(z_i|\mathcal{C}_i)\)（假设为对角高斯，输出均值 \(\mu_i\) 和方差 \(\sigma_i^2\)）近似后验。解码器 \(p_\theta(x|z_i, T_k)\) 从潜在变量和给定视角预测2D特征。
  - **基于集合的置换不变性**：编码器和解码器使用改进的Set Transformer结构，结合了相对位姿感知注意块（Pose-aware Attention Block, PAB），确保输入视图集合的置换不变性/等变性。
  - **训练目标**：主要损失为**留存视图预测损失**（held-out loss）：将观测集合分为上下文集 \(\mathcal{C}_i\) 和留存集 \(\mathcal{H}_i\)。编码器从上下文推断 \(z_i\)，解码器根据 \(z_i\) 和目标视角 \(T_k\) 预测留存特征 \(\hat{x}_{ik}\)，并用余弦相似度损失训练。这迫使潜在变量捕获视角稳定的语义，而非特定视角伪影。
  - **辅助损失**：文本对齐损失（确保输出嵌入与文本原型匹配）和平均特征锚定损失（防止特征漂移）。
  - **公式**：总损失 \(L(i) = L_{\text{view}}(i) + \beta \text{KL}[q_\phi||p] + \lambda_{\text{text}} L_{\text{text}}(i) + \lambda_{\text{avg}} L_{\text{avg}}(i)\)。

- **推理**：测试时使用所有可用视图作为上下文，编码器输出 \(\mu_i\)，然后映射回原始特征空间得到最终3D语义特征 \(e_i = h_\psi(\mu_i)\)。

### 6. 主要结论与发现

- Casper3D在所有数据集上显著优于零样本2D融合方法，证明概率推断比确定性聚合更有效。
- 即使不使用3D骨干蒸馏，Casper3D也具有竞争力；结合蒸馏后性能进一步提升，接近全监督上限。
- Casper3D对视图稀疏性鲁棒，在仅4个视图时仍远优于平均池化。
- 方法对2D骨干网无关，能受益于更强的基础模型。

### 7. 优点

- **新颖性**：将3D特征提升形式化为贝叶斯逆问题，引入变分推断和留存视图预测，与简单聚合有本质区别。
- **不确定性建模**：后验方差提供每点置信度，利于下游任务。
- **置换不变性**：基于Set Transformer的架构天然支持可变大小、无序的多视图集合。
- **轻量高效**：模型小（35.6M参数），推理快（14.4 ms），GPU内存低。
- **与语言空间兼容**：通过文本对齐损失保持开放词汇能力。

### 8. 不足与局限

- **依赖准确几何**：训练和评估时需要已知相机位姿和深度（如ScanNet提供的GT几何）。论文指出未来可用现成3D估计模型替代，减少对GT几何的依赖。
- **实验覆盖**：仅在室内RGB-D数据集上评估，未在室外或大规模场景（如KITTI、nuScenes）测试，泛化性待验证。
- **对比方法局限**：未包含一些更近期的基于扩散模型的方法（但论文发表时间较早，可能合理）。
- **偏见风险**：评估时使用固定文本提示，可能对某些类别有偏差；开放词汇任务本身依赖文本模板设计。
- **理论简化**：假设每点潜在变量独立，忽略点间上下文关系；后验分布为对角高斯，表达能力有限。
