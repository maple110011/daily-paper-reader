## 摘要
深度学习天气模型现在在运行速度快数个数量级的同时，达到了与数值天气预报相当的精度，但仅产生确定性预报，缺乏不确定性估计，这在极端天气事件的高风险决策中是一个关键缺口。本文提出基于神经正切核的不确定性量化（NTK-UQ），使用最后一层经验特征。理论分析预测，UQ质量依赖于架构，通过两种机制实现。第一，方差坍缩机制解释了UQ何时失效：当特征值截断秩接近特征空间的有效秩时，高斯过程修正项几乎消耗全部先验方差，破坏了对热带气旋和常规条件的区分能力；具有集中谱的架构（谱算子）需要激进截断（k ≤ 10），而基于注意力的模型可以容忍满秩计算。第二，分解性能取决于极端天气的非高斯、重尾结构：独立成分分析利用高阶统计量（峰度、负熵）分离重尾极端事件特征，比仅捕获二阶方差的奇异值分解实现更高区分度。一个数据驱动的选择规则根据特征特征谱集中比率选择ICA或SVD，为所有四种评估架构正确指定了更优的分解。与分割共形预测（自然事后基线）相比，NTK-UQ在90%覆盖率下实现了31-37%更尖锐的预测区间，并且独特地产生了随极端事件严重程度自适应缩放的区间，而共形预测因构造无法实现。该框架无需重新训练；推理时不确定性仅需每个样本进行一次矩阵-向量乘积。

## Abstract
Deep learning weather models now match numerical weather prediction accuracy while running orders of magnitude faster, but produce deterministic forecasts without uncertainty estimates, a critical gap for high-stakes decisions during extreme weather events. This paper proposes Neural Tangent Kernel-based uncertainty quantification (NTK-UQ) using last-layer empirical features. Theoretical analysis predicts that UQ quality is architecture-dependent through two mechanisms. First, a variance collapse mechanism explains when UQ fails: when the eigenvalue truncation rank approaches the effective rank of the feature space, the GP correction term consumes nearly all prior variance, destroying discrimination between tropical cyclones and routine conditions; architectures with concentrated spectra (spectral operators) require aggressive truncation ($k \leq 10$), while attention-based models tolerate full-rank computation. Second, decomposition performance depends on the non-Gaussian, heavy-tailed structure of extreme weather: Independent Component Analysis exploits higher-order statistics (kurtosis, negentropy) to isolate heavy-tailed extreme-event features, achieving higher discrimination than singular value decomposition, which captures only second-order variance. A data-driven selection rule chooses ICA or SVD from the feature eigenspectrum concentration ratio, correctly prescribing the superior decomposition for all four evaluated architectures. Compared to split conformal prediction (the natural post-hoc baseline), NTK-UQ achieves 31--37\% sharper prediction intervals at 90\% coverage, and uniquely produces \emph{adaptive} intervals that scale with extreme event severity, which conformal prediction cannot achieve by construction. The framework requires no retraining; inference-time uncertainty requires only a single matrix-vector product per sample.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：深度学习天气模型（如 FourCastNetV2、Pangu-Weather、Aurora、AIFS）在运行速度上超越传统数值天气预报数个数量级，且精度已可匹敌，但仅输出**确定性点预报**，缺乏**校准的不确定性估计**。对于极端天气事件（热带气旋、洪水、热浪等）的高风险决策（年均1430亿美元损失），不确定性信息至关重要。
- **现有局限**：深度集成（需训练多个副本，计算成本过高）、MC Dropout（校准差且需架构修改）、贝叶斯网络（计算开销大）、共形预测（提供分布自由覆盖保证，但产生**均匀区间宽度**，无法区分不同事件难度）。
- **目标**：提出一种**事后**、**无需重训练**、**推理开销小**的不确定性量化框架，能生成**自适应**（随事件严重性缩放）且**校准**的预测区间。

## 2. 方法论

### 2.1 核心思想：后层NTK-GP对偶

- 将预训练天气模型视为特征提取器 `φ(x)` 加预测头 `g(φ(x))`。后层特征 `φ(x)` 由ERA5再分析数据训练得到，编码了物理上有意义的大气结构。
- 定义经验核 `K(x, x') = φ(x)^T φ(x')`（后层经验神经正切核）。将模型视为高斯过程 `f ~ GP(0, K)`。
- 在测试点 x* 的GP后验方差（原始不确定性）：
  `σ²(x*) = ||φ̃(x*)||² + σ²_n - Σ_{j=1..k} [λ_j · (φ̃(x*)ᵀv_j)²] / (λ_j + σ²_n)`
  其中 `φ̃` 为中心化特征，`λ_j, v_j` 为特征矩阵SVD的特征值和右奇异向量，`σ²_n` 为噪声方差（从残差特征值尾部估计）。

### 2.2 关键技术细节

1. **后层特征提取**：通过前向hook捕获最后一层激活，对空间特征图应用多统计量池化（均值、标准差、min、max、25%/75%分位数），得到固定维度特征向量（架构相关：FCNv2->1536, Pangu->69, Aurora->65, AIFS->1024）。
2. **核分解**：直接求逆O(N³)不可行。中心化特征矩阵后，比较两种分解：
   - **SVD**：捕获最大方差方向（二阶统计）。
   - **ICA**：捕获统计独立成分（利用高阶统计：峰度、负熵），能分离极端事件的重尾特征。
3. **方差崩溃机制（命题1）**：当截断秩 k 接近特征空间有效秩时，GP修正项几乎消耗全部先验方差（R_k = C_k/P > 0.9），破坏区分能力。诊断：维持R_k < 0.9；架构需匹配截断（谱算子k≤10，注意力模型可满秩）。
4. **非高斯区分理论（命题2）**：极端天气特征呈非高斯、重尾分布，ICA利用高阶统计量能更好隔离极端事件信号，SVD仅捕获二阶方差（对低频、高方差常规模式偏置）。
5. **分解选择算法（算法1）**：根据特征谱集中比ρ = λ₁/Σλ_j 选择：
   - ρ > 0.8（集中谱）→ SVD + k≤10
   - ρ < 0.5（分散谱）→ ICA
   - 中间态 → 比较CRPS（最小化，同时保证覆盖率≥85%）
6. **事后校准缩放**：通过二分搜索学习每个变量、每个预报时效的缩放因子α，使原始不确定性 `σ_raw` 缩放后达到目标90%覆盖。等价于温度缩放。
7. **自回归特征提取**：在一个自回归 rollout 中从多个检查点提取特征，避免多次独立前向传播，节省计算量因子 |T|（本文6个时效）。

## 3. 实验设计

### 3.1 数据集与场景

- **极端事件**：从EM-DAT国际灾害数据库选取2021年事件，包括136洪水、63风暴（热带气旋Tauktae, Ida, Rai, Elsa）、5干旱、2极端温度（太平洋西北热浪），去重后**100个初始化日期**（每个日期对应事件发展前3天，即预报初始化阶段）。预报时效：6,12,24,48,72,120小时。
- **评估变量**：17个气象变量（6个地表+11个压力层）。

### 3.2 基准方法

- **分裂共形预测（Split Conformal Prediction）**：80/20分裂，非顺应性分数=每变量经验RMSE分位数（q0.90），产生均匀区间宽度。
- **对比自身变体**：NTK-UQ使用ICA vs SVD分解，以及不同rank k。

### 3.3 评估指标

- **覆盖（Coverage）**：90%预测区间中真实值落入比例，约束条件（85%-95%）。
- **锐度（Sharpness）**：平均区间宽度，越小越好（但需满足覆盖约束）。
- **CRPS**：连续排序概率分数，统一评估校准与锐度（越低越好）。
- **误差-不确定性斯皮尔曼相关系数ρ_s**：诊断区分度（>0.3视为良好）。
- **不确定性变异系数（CV）**：衡量区间自适应程度（CV>0.3表示显著样本间变化）。

## 6. 主要结论与发现

1. **NTK-UQ能实现校准的不确定性**：后事后校准达到89-91%覆盖，且能自适应缩放（ICA的CV显著高于SVD及共形预测）。
2. **分解方法选择至关重要**：**无通用分解方法**。ICA在3/4模型上达到有效覆盖且CRPS更低；SVD仅对Pangu有效，但数值不稳定。ICA通过利用高阶非高斯统计量，优于仅捕获二阶方差的SVD。
3. **架构驱动UQ质量**：谱集中型（SFNO）需要激进截断（k≤10）避免方差崩溃；注意力型（Perceiver, GNN-Transformer）可容忍满秩计算。这一关联通过命题1和谱衰变引理解释。
4. **NTK-UQ优于共形预测**：在81%的有效比较中（覆盖≥85%），NTK-UQ的区间更尖锐（31-37%），且产生自适应宽度（CV>0），而共形预测固有地产生均匀宽度（CV=0）。
5. **数据驱动选择规则有效**：算法1根据特征谱集中比ρ正确指定了所有4种模型更优的分解方法，无需穷尽尝试。
6. **空间自适应不确定性**：AIFS+ICA能在台风场景下产生空间变化的不确定性，与预报误差集中区域一致（图5），有利于区域化预警。

## 7. 优点

- **完全事后、无需重训练**：适用于任何预训练检查点，无需修改模型架构。
- **高效推理**：一次矩阵向量乘积，计算开销几乎可忽略。
- **理论基础扎实**：提供了方差崩溃和ICA优越性的理论分析（命题1、2），并有谱衰变引理支撑架构依赖性。
- **自适应性**：IA自适应区间强度缩放与天气事件严重性关联，解决了共形预测的均匀性缺陷。
- **空间扩展潜力**：AIFS的特征空间保留空间结构（d=1024），可实现网格点级不确定性；而池化模型（Pangu d=69）只能输出标量，体现了特征设计对UQ的影响。
- **开源可复现**：代码、校准矩阵、EM-DAT日期列表明文提供。

## 8. 不足与局限

- **评估数据有限**：仅2021年100个初始日期（去重后），时间单一，样本量不足。虽然定理3给出置信界，但极端事件时空依赖性强，实际有效样本量可能更低。

- **计算资源不大但未详述总成本**：仅有推理速度，缺少总GPU小时数、能源消耗等。
