## 摘要
贝叶斯推断为科学机器学习中的不确定性量化提供了原则性框架。然而，传统的贝叶斯方法通常需要为每次观测集解决新的推断问题，导致巨大的计算成本，阻碍了在线监控和数字孪生等实时应用。此外，在具有变化观测集的无限维函数空间上进行推断对现有的摊销推断方法构成了重大挑战。在这项工作中，我们提出了Flow-ABI，一个基于流的生成框架，用于回归和逆偏微分方程问题的摊销贝叶斯推断。它包含两个组件：(i) 函数先验模型，通过流匹配从历史数据和物理知识中学习表达性先验，以及 (ii) 集合条件函数后验采样器，将观测集映射到函数后验分布。学习到的后验模型自然适应变化、置换不变的观测集，并推广到不同的观测离散化。一旦训练完成，Flow-ABI能够在无需重新训练或迭代优化的情况下，对未见过的观测进行近乎实时的后验采样。所提出的方法可以无缝集成到广泛类别的科学机器学习框架中，包括物理信息神经网络和神经算子，用于不确定性感知的逆偏微分方程建模。实验表明，Flow-ABI准确捕获了高斯和非高斯后验分布，同时相对于黄金标准贝叶斯推断方法——哈密顿蒙特卡洛，实现了超过两个数量级的加速。这些结果表明Flow-ABI是科学机器学习中不确定性量化的一种有效、可扩展且计算高效的框架。

## Abstract
Bayesian inference provides a principled framework for uncertainty quantification in scientific machine learning. However, conventional Bayesian approaches usually require solving a new inference problem for each observation set, causing substantial computational costs that hinder real-time applications like online monitoring and digital twins. Furthermore, inferring over infinite-dimensional function spaces with varying observation sets poses major challenges for existing amortized inference methods. In this work, we propose Flow-ABI, a flow-based generative framework for amortized Bayesian inference in regression and inverse partial differential equation (PDE) problems. It consists of two components: (i) a functional prior model that learns expressive priors from historical data and physical knowledge through flow matching, and (ii) a set-conditioned functional posterior sampler mapping observation sets to functional posterior distributions. The learned posterior model naturally accommodates varying, permutation-invariant observation sets, and generalizes across different observation discretizations. Once trained, Flow-ABI enables near-real-time posterior sampling for previously unseen observations without retraining or iterative optimization. The proposed methodology can be seamlessly integrated with a wide class of scientific machine learning frameworks, including physics-informed neural networks and neural operators, for uncertainty-aware inverse PDE modeling. Experiments demonstrate that Flow-ABI accurately captures both Gaussian and non-Gaussian posterior distributions while achieving over two-order-of-magnitude speedups relative to the gold-standard Bayesian inference method, Hamiltonian Monte Carlo. These results show Flow-ABI is an effective, scalable, and computationally efficient framework for uncertainty quantification in scientific machine learning.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
Flow-ABI由两个组件构成：
1. **函数先验模型（FPM）**：通过流匹配（flow-matching）从历史数据或物理知识中学习函数空间上的表达性先验分布。
2. **集合条件函数后验模型（SFPM）**：使用条件流匹配（conditional flow matching）学习从观测集合到后验分布的映射，实现摊销推断。

### 关键技术细节
1. **函数先验模型（FPM）**：
   - 使用**函数编码器（FE）**，包含一个系数网络 \(NN_C\) 和一个基函数网络 \(NN_B\)。给定一个函数的离散表示（如观测值），系数网络输出一个 \(p\) 维系数向量 \(\psi \in \mathbb{R}^p\)；基函数网络输出坐标相关的基函数 \(\phi(t,x) \in \mathbb{R}^p\)。函数近似为 \(u(t,x) \approx \sum_{j=1}^p \psi_j \phi_j(t,x)\)，通过MSE损失训练。
   - 利用这些系数 \(\psi\) 样本，训练一个**两阶段流匹配模型**：
     - 第一阶段：训练一个基流模型 \(v_{\theta_{\text{FPM}}}\)，学习从高斯分布 \(N(0,I)\) 到系数分布 \(p_\psi\) 的线性概率路径（\(\xi_\tau = (1-\tau)\xi + \tau\psi\)），优化流匹配损失。
     - 第二阶段：通过蒸馏（distillation）训练一个一步生成器 \(G_{\theta_s}\)，直接从高斯噪声映射到系数，以加速采样。最终函数先验为 \(u_{\text{prior}}(t,x;\xi) = \sum_i [G_{\theta_s}(\xi)]_i \phi_i(t,x)\)。
   - 对于逆PDE问题，可利用自动微分（AD）或预训练神经算子（如DeepONet、FNO）从先验采样生成其他物理量的先验。

2. **集合条件函数后验模型（SFPM）**：
   - 使用**扩散Transformer（DiT）** 作为条件流匹配架构，条件为观测集 \(D_{\text{obs}}\)。
   - 观测集的表示：每个观测点（坐标、值、类型）通过随机傅里叶特征（RFF）编码坐标，再与观测值和类型指示符连接，投影到固定维度 \(d_{\text{model}}\)，形成无序的观测标记集。
   - 交叉注意力：将噪声潜在变量 \(\epsilon_\tau\) 作为查询，观测标记作为键和值，通过掩码机制处理变数量的观测（填充并掩码），保证置换不变性。
   - 训练：优化流匹配损失 \(L_{\text{SFPM}} = \mathbb{E}_{\tau, \epsilon, \xi, D_{\text{obs}}} \| v_\theta(\epsilon_\tau, \tau, D_{\text{obs}}) - (\xi - \epsilon) \|_2^2\)，其中 \(\xi\) 为真实潜在系数。
   - 推理时：给定观测 \(D_{\text{obs}}\)，通过ODE积分（如5步RK4）生成后验潜在系数 \(\xi_{\text{post}}\)，再经一步生成器 \(G_{\theta_s}\) 和基函数解码为后验函数样本。
   - 后验分布 \(\hat{Q}_{\text{post}}(u|D_{\text{obs}})\) 可直接用于计算均值、方差、可信区间等统计量，且采样可并行批处理。

### 公式与算法流程（文字描述）
1. 训练FPM：用历史函数样本训练FE → 提取系数 \(\psi\) → 训练基流模型 → 蒸馏得到一步生成器。
2. 训练SFPM：从先验采样 \((\xi, u)\) → 根据测量模型生成观测 \(D_{\text{obs}}\)（含噪声） → 构建成对样本 \((\xi, D_{\text{obs}})\) → 训练条件流匹配模型。
3. 推理：输入新观测 \(D_{\text{obs}}\) → DiT条件流ODE → 采样 \(\xi_{\text{post}}\) → 一步生成器 → 基函数解码 → 后验函数样本。
