## 摘要
先验拟合网络（PFN）是一类有前景的表格基础模型，能够进行上下文学习，即整个带标签的训练集作为上下文提供，并在单次前向传递中为测试查询生成预测。然而，许多PFN架构中的二次缩放自注意力机制使得对非常大的训练数据集的推理变得不可行。我们提出CRUMB（使用最小化MMD批处理的聚类检索），一种三阶段推理包装器：（i）对测试查询进行聚类，（ii）通过贪婪地最小化最大均值差异（MMD）为每个聚类选择一个小型、分布匹配的训练子集，（iii）在每个缩减上下文的批次上执行精确的PFN推理。CRUMB与架构无关，无需重新训练。在包含51个数据集的TabArena基准上，跨三种PFN架构（TabPFNv2、TabICLv1、TabICLv2）进行评估，我们显示CRUMB优于类似的最新上下文选择策略。我们还显示CRUMB对协变量漂移具有弹性，因为MMD最小化步骤自然有助于对齐训练上下文分布以匹配当前测试批次分布。

## Abstract
Prior-fitted networks (PFNs) are a promising class of tabular foundation models that perform in-context learning, whereby the entire labelled training set is supplied as context, and predictions for test queries are produced in a single forward pass. However, the quadratically scaling self-attention mechanism in many PFN architectures makes inference prohibitive for very large training datasets. We propose CRUMB (Clustered Retrieval Using Minimised-MMD Batching), a three-stage inference wrapper that (i) clusters the test queries, (ii) selects a small, distributionally matched training subset for each cluster by greedily minimising the maximum mean discrepancy (MMD), and (iii) runs exact PFN inference on each reduced-context batch. CRUMB is architecture-agnostic and requires no retraining. On the 51-dataset TabArena benchmark, evaluated across three PFN architectures (TabPFNv2, TabICLv1, TabICLv2), we show that CRUMB outperforms similar state-of-the-art context selection strategies. We also show that CRUMB is resilient to covariate drift, as the MMD-minimisation step naturally helps align the training context distribution to match the current test batch distributions.

- **研究目标**：设计一种无需重新训练、架构无关的推理加速方法，在不显著损失预测性能的前提下大幅降低 PFN 的推理成本，并提升对测试数据分布偏移的鲁棒性。
- **整体含义**：本文提出的 CRUMB 方法通过将测试查询聚类，并为每个簇选择分布匹配的少量训练子集，实现了上下文的高效批处理，使得 PFN 能够应用于之前无法处理的大规模表格数据场景。

## 2. 方法论

### 核心思想
CRUMB 是一个三阶段的推理包装器：
1. **阶段 1：测试查询聚类** – 使用 k-means 算法将测试集划分为 K 个簇。
2. **阶段 2：基于 MMD 的训练子集选择** – 对每个测试簇，通过**贪心最小化最大均值差异（MMD）**（即核 herding）从完整训练集中选取 n 个样本，使所选子集的分布与该测试簇的分布尽可能匹配。
3. **阶段 3：批处理 PFN 推理** – 对每个（测试簇，训练子集）组合执行一次 PFN 前向传播，所有簇内测试点共享同一上下文，实现 GPU 高效批处理。

### 关键技术细节
- **MMD 优化目标**：对于测试簇 \(C_k\)，选择子集 \(S_k\) 使
  \[
  \text{MMD}^2(\hat{P}_{C_k}, \hat{P}_{S_k}) = \frac{1}{n^2}\sum_{x_i,x_{i'}\in S_k}\kappa(x_i, x_{i'}) - \frac{2}{n|C_k|}\sum_{x_i\in S_k}\sum_{x_j^*\in C_k}\kappa(x_i, x_j^*)
  \]
  其中 \(\kappa\) 为高斯 RBF 核，带宽通过中位数启发式确定。
- **贪心选择**：每次迭代选择使当前 MMD 下降最大的训练点，可通过 batched 更新（每步选 Top-B 个点）加速。
- **加速手段**：
  - **随机傅里叶特征（RFF）**：将核函数近似为低维嵌入，降低计算复杂度。
  - **早停机制**：当相对 MMD 改善低于阈值（如 \(10^{-4}\)）且连续若干次检查后停止，自动调整上下文大小。
- **算法流程**（伪代码见 Algorithm 1）：标准化特征 → k-means 聚类测试点 → 对每个簇用 GreedyMMD 选择子集 → 执行 PFN 推理。

## 6. 主要结论与发现

1. **性能优异**：在固定上下文预算下，CRUMB 显著优于均匀采样和 MICP（\(p_{\text{adj}}<0.001\)），与 per-query k-NN 无显著差异（\(p_{\text{adj}}=0.106\)），但仅需 K 次前向传播（通常 K=20），比 k-NN 减少 10× 以上推理时间。
2. **跨架构与比例一致性**：在三种 PFN 架构、五种采样比例下，CRUMB 平均排名领先于 MICP 和均匀采样（Table 2, Figure 3）。
3. **大规模数据集适用性**：在大规模数据集（>50k）上，CRUMB 结合早停可在更小的上下文大小下获得与 MICP 相当或更优的性能（Figure 4）。
4. **对协变量漂移的鲁棒性**：随着漂移强度增加，CRUMB 与 MICP 的性能差距从 +4.9% 扩大至 +17.1%，表明 CRUMB 通过测试侧聚类和 MMD 匹配自然适应分布偏移。
5. **消融结果**：MMD 检索优于 Centroid-NN 和 Voronoi-Uniform（Appendix B），且 RFF 近似几乎不损失精度（Appendix D）。

## 7. 优点

- **架构无关且无需重训**：CRUMB 可作为即插即用的推理包装器，适用于任何 PFN 模型。
- **计算效率高**：将全训练集复杂度 \(O(N^2)\) 降至 \(O(N)\) 预处理 + \(O(n^2)\) 每批次推理，且通过批处理将前向传播次数从 T 次降至 K 次（\(K\ll T\)）。
- **分布自适应性**：MMD 最小化自然对齐训练上下文与测试批次分布，对协变量漂移鲁棒。
- **可扩展加速**：支持 RFF 近似、批量贪心选择和早停，在几乎无精度损失下显著降低预处理时间。
- **实验严谨**：统计检验校正、多维度消融、跨模型跨种子验证，结论可信度高。

## 8. 不足与局限

- **需要批量测试点**：CRUMB 需要一次性获取所有测试查询才能聚类；原生的流式处理不支持。文中附录 C 提出了缓存质心的在线变体，但退化为与 MICP 相似的推理模式，分布匹配优势减弱。
- **聚类限制**：使用欧氏距离的 k-means 假设各向同性簇，在极高维度或混合类型特征上可能效果不佳；MMD 同样采用各向同性高斯 RBF 核（中位数带宽），未针对数据集结构自适应。
- **常数开销**：虽然预处理复杂度为 \(O(N)\)，但常数因子可能仍较大（涉及 \(O(Nd(T+Kn))\)），对百万级数据集可能仍是瓶颈。
- **依赖 PFN 基座**：CRUMB 继承底层 PFN 的性能天花板；若 PFN 预训练先验与数据集不匹配，任何上下文选择都无法完全补偿。
- **未结合微调**：为隔离上下文选择效果，实验未采用微调；文中承认若结合微调（如 LoCalPFN、MixturePFN）可能进一步提升，这是未来方向。
- **应用限制**：当前仅验证于表格数据任务，对 NLP 或视觉 PFN 的适用性未讨论。
