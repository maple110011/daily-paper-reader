## 摘要
组合先验描述了深度贝叶斯模型中分层函数的通用属性，其中具有随机权重的深度神经网络是一个典型例子。在宽网络极限下，先验是一个具有深度依赖核的高斯过程，其随着深度增加的行为已通过该核得到广泛研究。在这里，我们研究另一种情况，其中每一层本身是一个向量值高斯过程，我们的目标是类似地理解随着深度增加先验的极限行为。先前的高斯过程工作已表明，对于RBF核和一定范围的带宽$r$，先验在极限下退化，收敛到常数函数集合——这作为概率模型没有用处。在本文中，我们建立了几个新结果。首先，我们确定了一个尖锐的带宽阈值$r_c(d) = Θ(\sqrt{d})$，高于该阈值极限是退化的，加强了先前的界限。其次，更重要的是，我们证明对于低于阈值$r_c(d)$的$r$，先验收敛到极限分布$π_{\bar{Z}}$。我们还证明这些分布是非退化和非高斯的，坐标之间的依赖关系不消失。与先前已知的退化机制相反，深度高斯过程先验因此可以允许非平凡极限。在经验上，我们验证了在维度$d$范围内的阈值，并展示了极限分布$π_{\bar{Z}}$的复杂多模态行为——这种机制随着$d$增加而变得越来越窄，如果没有知道阈值将很难识别。

## Abstract
Compositional priors describe the generic properties of layered functions in deep Bayesian models, where deep neural networks with random weights are a canonical example.In the wide-network limit, the prior is a Gaussian process with a depth-dependent kernel, and its behaviour as depth grows has been extensively studied through this kernel. Here, we study another case, where each layer itself is a vector valued Gaussian process, and our aim is similarly to understand the limiting behaviour of the prior as depth grows.   Previous GP work has established that for the RBF kernel and a certain range of bandwidths $r$, the prior degenerates in the limit, converging to the set of constant functions -- which is not useful as a probabilistic model. In this paper we establish several new results. First, we identify a sharp bandwidth threshold $r_c(d) = Θ(\sqrt{d})$ above which the limit is degenerate, strengthening the earlier bounds. Second, and more importantly, we show that for $r$ below the threshold $r_c(d)$ the prior converges to a limit distribution $π_{\bar{Z}}$. We also prove that these distributions are non-degenerate and non-Gaussian, with non-vanishing dependence between coordinates. In contrast to the previously known degenerate regime, deep Gaussian process priors can therefore admit non-trivial limits.   Empirically, we verify the threshold across a range of dimensions $d$, and demonstrate a complex multimodal behaviour of the limit distributions $π_{\bar{Z}}$ -- a regime that becomes increasingly narrow with $d$ and would be hard to identify without knowing the threshold.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将深层GP的迭代过程建模为**耦合马尔可夫链**。考虑n个输入点，每层应用同一个随机函数Gi（采样自中心化向量值GP，RBF核k(x,x')=exp(-||x-x'||²/(2r²))）。链定义为：$\bar{Z}_{i+1} = G_i(\bar{Z}_i)$，其中$\bar{Z}_i = (\bar{Z}_{i,1},...,\bar{Z}_{i,n})$。关键观察：不同轨迹通过共享Gi耦合。利用成对距离$v_i = ||\bar{Z}_{i,s} - \bar{Z}_{i,t}||$形成标量马尔可夫链：$v_{i+1}^2 = 2(1 - \phi(v_i)) X_i$，其中$X_i \sim \chi^2_d$，$\phi(t)=e^{-t^2/(2r^2)}$。
- **关键技术细节**：
  - **阈值推导**：通过对对数链$L_i = \log v_i^2$的增量均值分析，得到$E[L_{i+1} - L_i] = \psi(d/2) + \log 2 - 2\log r$。令该均值为零解得临界带宽$r_c(d) = \sqrt{2 e^{\psi(d/2)/2}}$，渐近等价于$\sqrt{d}$。
  - **超临界退化证明**：利用不等式$1-e^{-x} \le x$得到全局上界$v_{i+1}^2 \le v_i^2 X_i / r^2$，再通过大数定律证明$L_i/i \to \rho_d < 0$ a.s.，即指数收敛到0。
  - **亚临界非退化与极限存在性**：当$r < r_c(d)$时，通过Foster-Lyapunov漂移准则（构造“帐篷”型Lyapunov函数$V(L) = (L_0 - L)_+ + (L - L^0)_+$）证明标量链是正Harris回归的，从而存在唯一不变分布$\pi_v$；进而通过全位置链的耦合距离向量链的联合Lyapunov函数（平方和对数距离），证明$\bar{Z}_i$收敛到唯一不变分布$\pi_{\bar{Z}}$。
  - **非高斯性证明**：利用特征函数法，假设$(Z_{\infty,1}, Z_{\infty,2})$是联合高斯的，则其差$V_\infty$是各向同性高斯，其范数平方$v_\infty^2$服从缩放$\chi^2_d$。但代入标量链的更新方程后，通过特征函数推导会导致矛盾（除非分布退化），从而证明不可能是高斯分布。
  - **坐标依赖性与上界**：利用Jensen不等式和凹性（$H(L)$严格凹且递减）给出$E_{\pi_v} \log v^2 \le L^*$，其中$L^* = \log(2r^2\alpha)$，$\alpha$由$(1-e^{-\alpha})/\alpha = (r/r_c)^2$确定。将r参数化为$r = \lambda r_c$，则$L^*$与独立高斯基线之差为$\log(\lambda^2\alpha(\lambda))$，负且独立于d，证明坐标间依赖的存在且可通过$\lambda$调节强度。

## 6. 论文的主要结论与发现

1. **尖锐阈值**：存在一个确切的带宽阈值 $r_c(d) = \sqrt{2 e^{\psi(d/2)/2}}$，渐近于 $\sqrt{d}$。当 $r > r_c(d)$ 时，成对距离指数收敛到0（退化）；当 $r < r_c(d)$ 时，距离不消失且存在唯一非平凡平稳分布。
2. **非退化极限**：在亚临界区域，深层GP先验收敛到唯一不变分布 $\pi_{\bar{Z}}$，该分布具有**非高斯性**：虽然每个坐标边际是标准高斯，但任意两个坐标的联合分布不是高斯分布。
3. **坐标依赖**：坐标之间存在依赖，且依赖强度可通过 $\lambda = r/r_c$ 调节。通过 Jensen 上界给出了依赖的定量刻画，且该依赖在高维下仅在 $\lambda$ 极接近1时可见（如d=100时 $\lambda \in (0.99,1)$）。
4. **多模态结构**：经验显示 $\pi_{\bar{Z}}$ 在近临界区域呈现复杂多模态（簇、斑、弧等），且各链独立样本的结构各异，进一步佐证非高斯性。
5. **理论贡献**：首次证明组合GP先验可以存在非平凡深度极限，并给出了精确的分界条件和极限性质，推翻先前“只能退化”的认知。
