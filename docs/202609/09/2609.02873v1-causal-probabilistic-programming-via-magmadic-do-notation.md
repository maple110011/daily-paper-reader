## 摘要
我们引入了一种用于因果概率编程的do-notation元语言。该元语言基于magmads：非结合单子。我们从非结合性和概率编程的原语中推导出因果概率编程结构。

## Abstract
We introduce a do-notation metalanguage for causal probabilistic programming. The metalanguage is based on magmads: non-associative monads. We derive causal probabilistic programming constructs from non-associativity and the primitives of probabilistic programming.

## 论文核心问题与整体含义

- **研究动机**：传统概率编程中的 do-notation 建立在单子（monad）的结合律之上，而因果推断中关键的“干预”（intervention）操作无法被这种结合性的语义所捕捉。论文以 Simpson 悖论的临床数据为例，说明单纯的观测条件化（observe）会受混杂变量影响而得出错误结论，而因果推断需要一种能够表达“如果我们干预某变量”的语义结构。
- **核心问题**：如何为因果概率编程提供一种统一、有严格语义基础的语言结构，使得干预（intervene）、条件（conditional）等因果推断操作能够从更基本的概率编程原语（do 与 observe）中系统性推导出来，而非各自引入新的专门原语。
- **整体含义**：论文提出以 magmads（非结合单子）作为因果概率编程的语义基础，将非结合性本身作为一种结构资源来编码因果依赖关系。这种视角揭示了干预操作并非独立的语法扩展，而是非结合性与概率归一化语义共同作用的自然产物。

## 方法论

- **核心思想**：建立一套基于 magmads 的 do-notation 元语言。与经典 do-notation 的右结合默认不同，此处采用左结合语义；非结合性使得嵌套 do 无法简单折叠，从而为因果结构提供了必要的表达空间。
- **Magmads 的形式定义**：一个 magmad 由三元组 (T, η^T, β^T) 构成——集合上的类型构造 T、单位（unit）η 和绑定（bind）β，满足左单位律与右单位律，但不要求结合律（结合律恰是单子与 magmad 的区别）。因此，magmad 是单子的严格推广。
- **Magmadic do-notation 的语法规则**：定义了四条递归规则（i-iv），覆盖空 return、单行绑定、双行绑定和两行以上绑定的归约方式。规则 (iv) 利用 m = β(m₁; λx.β(m₂; λy.η(x,y))) 将多行 do 块归约为两行形式。由于缺乏结合律，嵌套 do 的求值顺序成为语义的有机组成部分。
- **归一化分布的 magmad**：定义在集合上的有限形式化分布 N(X)，系数非负且和为 1（成功）或 0（失败）。绑定操作的公式表达为带归一化分母的条件化联合分布。该构造构成一个 magmad 而非单子——归一化语义本身破坏结合律。
- **条件概率的重构**：在 do-notation 中，条件概率 P(a₁...aₙ | b₁...bₘ) 可表达为：先联合采样 (v₁...vₖ) ← p，然后对每个 bᵢ 执行 ( ) ← (observe bᵢ vbᵢ)，最后返回 (a₁...aₙ)。这把贝叶斯规则规约为“分布生成 + 观测约束”的基本模式。
- **Identify 算法与 ID 算法**：论文将 Shpitser 和 Pearl 的因果可识别性算法重建为仅含 do 和 observe 的重写规则。Identify 处理单个混淆分量内部的条件化与递归分解；ID 算法则先将目标集外变量消去，对每个混淆分量 Q_Si 做独立条件化，再以 do-notation 组合各部分结果。原文的乘除法运算被完全替换为 do/observe 推导。
- **Intervene 构造**：引入单一导出构造 `(intervene p withModel G setting (v...) to (x...) in (y...))`，它等价于 ID 算法的求值结果——因此每个干预表达式都能被系统改写为不含干预原语的基本概率程序，这是论文的核心技术宣言。
- **相关实现**：作者提供了基于 Racket 的公开实现（do 库 v0.1.0），附录包含从干预表达式到基础 do 程序的多阶段自动改写示例（如 front-door 准则与 napkin 问题），展示了方法在具体代码层面的可执行性。

## 主要结论与发现

- 非结合性（magmadic 语义）足以作为因果依赖语法的结构来源——干预构造可以在不引入任何新原语的情况下从 do 与 observe 中推导出来；
- 归一化概率分布确实构成 magmad 而非单子，这一代数事实成为因果编程元语言语义的基础；
- 经典的因果可识别性算法（SP08 的 ID/Identify）可以被翻译为只包含 do-notation 的条件化程序，说明因果推断与概率编程的语法表达力存在深层同构；
- 通过重写系统，每一个干预表达式都可得到一个等价的、不含干预原语的基本概率程序，从而给出了因果算子的归约语义。
