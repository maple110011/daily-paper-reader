## 摘要
我们正处于一个光谱数据可用性前所未有的时代，APOGEE、GALAH 和 DESI 等巡天项目正在观测数百万颗恒星。然而，数据是异质的，迄今为止，利用不同巡天项目之间协同效应的努力仍然有限。特别是，缺乏能够结合来自不同巡天项目的光谱数据以改进物理参数推断的原则性方法。在这项工作中，我们提出了一种用于光谱数据融合的新方法 MUSHY。MUSHY 是一种摊销贝叶斯推断方法，使用具有多模态输入的整流流模型来学习物理参数的后验分布。利用通过 ATLAS12/SYNTHE 生成的合成光谱，并包含真实的仪器效应和噪声，我们证明 MUSHY 能够从任意巡天项目的组合中精确推断物理参数，且后验校准良好；多模态输入比单一巡天数据对后验提供更强的约束。这项工作为异质来源光谱数据的原则性结合铺平了道路。

## Abstract
We are in an era of unprecedented spectroscopic data availability, with surveys such as APOGEE, GALAH, and DESI observing millions of stars. However, data are heterogeneous and to date, efforts to exploit synergies between surveys have been limited. In particular, there is a lack of principled methods that combine spectroscopic data from different surveys to improve inference of physical parameters. In this work we present a new method, MUSHY, for spectroscopic data fusion. MUSHY is an amortized Bayesian inference method, using a rectified flow model with multimodal inputs to learn a posterior distribution over physical parameters. Using synthetic spectra generated via ATLAS12/SYNTHE, including realistic instrumental effects and noise, we demonstrate that MUSHY can precisely infer physical parameters with well-calibrated posteriors from any combination of surveys, with multimodal inputs providing stronger constraints on the posterior than single-survey data alone. This work paves the way for principled combination of spectroscopic data from heterogeneous sources.

## 2. 方法论

### 2.1 核心思想

- MUSHY 属于**摊销贝叶斯推断**（amortized Bayesian inference）：训练一个条件生成模型，在模拟数据上学习后验分布 \(p(\theta \mid x_1,\dots,x_n)\)，使新数据的推断只需一次前向/ODE 积分，无需每颗恒星重新拟合。
- 使用**条件整流流模型**（conditional rectified flow）作为后验采样器，并以 **DiT** 作为骨干网络。
- 通过多模态条件建模，支持任意数量、任意子集的巡天输入，例如仅 APOGEE、仅 GALAH、APOGEE+GALAH、三巡天联合等。

### 2.2 架构与流程

- **输入表示**：任意巡天子集的光谱先由冻结的、预训练的自监督**通用光谱 tokenizer** 编码为公共潜在空间 token，以缓解不同巡天之间的异质性。
- **多模态条件编码**：各巡天 token 拼接后，经过轻量 Transformer encoder，得到条件序列 \(C \in \mathbb{R}^{L \times d}\)，其中 \(L=\sum_{s\in A} L_s\)，\(A\) 为可用巡天集合。
- **后验生成**：从高斯噪声 \(\theta_0 \sim \mathcal{N}(0,I)\) 出发，条件整流流学习速度场 \(v_\phi(\theta_t,t,C)\)，并通过 cross-attention 关注条件序列 \(C\)。从 \(t=0\) 到 \(t=1\) 积分 ODE，得到后验样本 \(\theta_1 \sim p(\theta \mid x_1,\dots,x_n)\)。
- **训练策略**：训练时使用 **modality dropout**，随机丢弃部分巡天，使模型学会处理任意巡天组合。
- **模型规模**：仅 2 个 conditioner block + 2 个 DiT block，embedding 维度 384，8 个 attention head，总可训练参数约 12M。
