## 摘要
高维、无分箱的神经模拟推断通常依赖于神经比率估计，该方法使用表达能力强的监督模型来估计密度比，但学习到的比率本身既不能提供显式的归一化密度，也不能提供生成模型。基于流的代理模型则能够进行可处理的密度评估和高效采样，但残余的密度估计误差可能限制复杂隐式分布的精度。我们提出混合神经密度估计，它使用流来定义与参数无关的参考分布，并使用分类器来估计目标分布与参考分布的密度比。将学习到的比率乘以参考密度，可得到可评估的目标密度代理。该比率还为积分和重采样提供重要性权重。我们展示这种表示如何定义一个精确的 Asimov 数据集，其最大似然拟合可返回生成参数。我们还展示可处理的参考分布如何为伪实验提供可再生的样本，以及如何使方法能够降低预期检验统计量计算的蒙特卡洛方差。我们在一个由高能物理测量启发的玩具统计模型中演示了该构建，但该模型的精确密度是解析已知的。

## Abstract
High-dimensional, unbinned neural simulation-based inference often relies on neural ratio estimation, which uses expressive supervised models to estimate density ratios, but a learned ratio by itself provides neither an explicit normalized density nor a generative model. Flow-based surrogate models instead enable tractable density evaluation and efficient sampling, but residual density-estimation errors can limit precision for complex implicit distributions.   We propose \textit{hybrid neural density estimation}, which uses a flow to define a parameter-independent reference distribution, and classifiers to estimate target-to-reference density ratios. Multiplying a learned ratio by the reference density gives an evaluable target density surrogate. The ratio also provides importance weights for integration and resampling. We show how this representation defines an exact Asimov dataset, whose maximum likelihood fit returns the generating parameters. We also show how the tractable reference supplies renewable samples for pseudo-experiments and how it enables methods to reduce the Monte Carlo variance of expected test statistic calculations.   We demonstrate the construction in a toy statistical model motivated by high-energy physics measurements, but for which the exact densities are known analytically.

- **另一条路线**：基于流的神经密度估计（NDE）可给出可评估的归一化密度与高效采样，但**残余的密度估计误差**会损害精度敏感推断——两个独立训练的流可能通过边际分布检查，其密度比仍存在偏差。
- **核心问题**：如何同时获得「可评估的归一化密度」「可生成样本」和「高精度密度比」，并支撑频率学派的无分箱 Asimov 数据集构建与伪实验生成。
- **整体含义**：论文提出 **hNDE（混合神经密度估计）**，把 NRE 的比值精度与流生成模型的可评估/可采样能力结合，使 NSBI 分析在无需对每个参数点单独训练生成器的前提下，完成似然评估、伪实验生成与期望灵敏度计算。

## 2. 方法论

### 核心思想
- 用**一个参数无关的归一化流** $q_\phi(x)$ 定义参考分布；用**分类器**学习每个目标假设到参考的密度比 $r_\psi(x;\theta) \simeq p(x;\theta)/q_\phi(x)$。
- 二者相乘得到可评估的归一化目标密度代理：$\hat{p}_{\text{hNDE}}(x;\theta) = q_\phi(x)\, r_\psi(x;\theta)$。即使 $q_\phi \neq p_{\text{ref}}$，只要比值精确即可恢复目标。
- 比值同时充当**重要性权重**，用于积分与重采样。参考分布只需可评估、易采样，并在目标非零处非零。

### 关键技术细节
- **分类器→比值**：平衡训练下最优分类器 $c^\star = p/(p+p_{\text{ref}})$，故 $r_\psi \propto c_\psi/(1-c_\psi)$；总体归一化约定 $\mathbb{E}_{q_\phi}[r_\psi(\cdot;\theta)]=1$。
- **有限样本归一化**：给定加权参考样本 $\{x_m,\omega_m\}$，定义 $Z(\theta)=\sum_m \omega_m r_\psi(x_m;\theta)$ 与 $\tilde r_\psi = r_\psi/Z$，使 $\sum_m \omega_m \tilde r_\psi(x_m;\theta)=1$ 精确成立（仅修正整体尺度，**不修复局部偏差**）。
- **扩展似然**：$\nu(x;\theta)=\sum_s \lambda_s(\theta)p_s(x;\theta)$，各过程用共享参考流表示 $r_{s,\psi}\simeq p_s/q_\phi$；$\hat{h}(x;\theta)=\sum_s \lambda_s \tilde r_{s,\psi}$，参考因子 $q_\phi$ 在剖面似然比中抵消。
- **Asimov 构建（Algorithm 2）**：在生成点 $\theta_A$ 取参考样本，令 $w_m^A = \omega_m \tilde h(x_m;\theta_A)$，满足 $\sum_m w_m^A = \lambda(\theta_A)$ 精确成立；有限加权对数似然为 $\hat\ell_A(\theta) = -\lambda(\theta) + \sum_m w_m^A \log[q_\phi \tilde h] + \log f(a_A;\alpha)$。
- **精确闭包**：在正性与辅助似然于 $\alpha_A$ 取极大等条件下，$\hat\Delta\ell(\theta)=-\sum_m w_m^A[u_m-1-\log u_m]+\log\frac{f(a_A;\alpha)}{f(a_A;\alpha_A)}\le 0$，故**生成点是有限似然的全局最大点**（无需可微）。关键要求：**在扫描的每个参数点对完整（含形状系统）参数依赖比值重新归一化**，仅归一化名义比值只对纯产额方向成立。
- **统计性质**：推导了固定归一化与同样本归一化两种情形下 $-2\hat\Delta\ell$ 与 $\hat t_A(\mu)$ 的期望与方差，指出同样本归一化下误差项 $U_\theta$ 包含归一化涨落的协方差；剖面只贡献 $o(M^{-1})$ 方差但有 $O(M^{-1})$ 偏差。
- **神经重要性采样（NIS, Algorithm 3）**：利用流的隐空间映射，定义误差贡献幅度 $A(x)=[\sum_k a_k U_{\theta_k}^2]^{1/2}$，最优提议 $g^\star \propto q_\phi A$；用第二个流 $g_\eta$ 以加权极大似然拟合，并采用**防御混合** $g_\epsilon=(1-\epsilon)g_\eta+\epsilon q_\phi$ 保证尾部支撑，权重上界 $1/\epsilon$。同样本归一化在 NIS 下保持一致，积分不变。

## 6. 主要结论与发现

- hNDE 的乘积表示在精确比值下可恢复目标密度，给出**可评估的归一化密度代理与可再生的采样器**，扩展了 ATLAS 的比值式 NSBI 到生成式密度模型。
- **精确 Asimov 闭包**：在完整参数依赖比值于同一样本上归一化时，生成点是有限加权似然的全局最大点，对产额参数与形状参数均成立；未做完整归一化时最佳拟合会明显偏离（示例中从 $(1,0)$ 漂移到约 $(0.635,0.0106)$）。
- **NIS 增益**：$M=4096$ 时 $q_{0,A}$ 的 IQR 从 0.049 降至 0.015，全扫描 RMS 从 0.055 降至 0.020，增益因子 $G\approx5.4\sim10.4$，相当于把积分样本量需求降低约 5–10 倍。
- **hNDE 优于纯流**：同数据下纯流似然最小值漂移到 $\hat\mu\approx3$，而 hNDE 与解析拟合差仅 0.05（统计误差约 0.56）。
- **验证必须外部化**：闭包只证明与「学习到的似然」一致，**不能证明与原始模拟器一致**；5% 错配演示表明 hNDE 内部一致但模拟器系综分布与 Asimov 预测出现偏差。

## 7. 优点

- **方法论优雅**：用「流定参考 + 分类器学比值」的简单代数分解，同时获得归一化密度、生成采样与高精度比值，避免对每个参数点训练生成器。
- **理论保证强**：给出有限样本 Asimov 的全局极大性与精确闭包证明，并完整推导期望/方差、同样本归一化协方差与 NIS 最优提议（含防御混合）。
- **工程可操作性**：$q_\phi$ 在剖面似然比中抵消，降低评估成本；参考可随时按需生成，突破固定 MC 池的分辨率限制。
- **科学诚信**：明确区分「学习模型内部一致性」与「对模拟器有效性」，专设模型错配失败案例，并公开可复现代码。
- **实验自洽**：解析密度作为客观基准，NIS 用独立基准与多次重复量化增益。

## 8. 不足与局限

- **验证范围有限**：仅一个五维玩具模型、少量生成点；无真实 HEP 数据或与 ATLAS 实现的端到端对比，结论的外推性未验证。
- **参考支撑与重叠要求**：$q_\phi$ 必须在整个推断参数域覆盖所有目标；尾部分布覆盖不足会产生巨大比值，导致训练困难、少数事件主导加权样本。
- **不修复分类器偏差**：经验归一化只调整整体尺度，局部偏差、校准误差仍需独立校准/系综稳定性/多维重加权检查。
