## 摘要
当模型包含许多相关参数时，贝叶斯变量选择在计算上变得具有挑战性。我们研究了分段确定性马尔可夫过程（PDMP）采样器，作为传统马尔可夫链蒙特卡罗方法在尖-板变量选择中的连续时间替代方案。在粘性PDMP采样器中，活跃参数连续演化直至达到零，此时它们可能停留随机时长后再重新进入模型。当一个参数进入或离开模型时，其余参数继续沿确定性流演化，这为探索具有强相关参数的后验分布提供了一种潜在有利机制。我们做出了两项方法论贡献。首先，我们将现有的粘性PDMP方法从独立的尖-板先验扩展到相依模型先验和相依板分布。其次，我们研究了使用无偏随机梯度来降低当似然分解为多个因子时变量选择的计算成本，同时保持相同的目标分布。我们将这些扩展应用于两个心理测量模型：高斯随机截距交叉滞后面板模型和序数马尔可夫随机场。对于前者，边际化产生固定维度的充分统计量表示，从而允许高效的模型评估；对于后者，模型可分解，从而能够对个体节点贡献进行子采样。在模拟研究中，我们将ZigZag、Bouncy Particle和Boomerang动力学与可逆跳跃MCMC进行比较，并考察先验依赖性和随机梯度子采样对采样效率的影响。我们使用一项关于心理健康的实证研究数据来展示该方法。最后，我们讨论了使用PDMP采样器进行贝叶斯变量选择的优势与挑战。

## Abstract
Bayesian variable selection becomes computationally challenging when models contain many dependent parameters. We study Piecewise Deterministic Markov Process (PDMP) samplers as a continuous-time alternative to conventional Markov chain Monte Carlo for spike-and-slab variable selection. In sticky PDMP samplers, active parameters evolve continuously until they reach zero, where they may remain for a random duration before re-entering the model. While one parameter enters or leaves the model, the remaining parameters continue to evolve along the deterministic flow, offering a potentially advantageous mechanism for exploring posteriors with strongly dependent parameters. We make two methodological contributions. First, we extend existing sticky PDMP methods beyond independent spike-and-slab priors to dependent model priors and dependent slab distributions. Second, we investigate the use of unbiased stochastic gradients to reduce the computational cost of variable selection when the likelihood decomposes into many factors while retaining the same target distribution. We study these extensions to two psychometric models: a Gaussian random intercept cross-lagged panel model and an ordinal Markov random field. For the former, marginalization yields a fixed-dimensional sufficient-statistic representation that permits efficient model evaluation. For the latter, the model factorizes, which enables subsampling over person-node contributions. In simulation studies, we compare ZigZag, Bouncy Particle, and Boomerang dynamics with reversible-jump MCMC, and examine the effects of prior dependence and stochastic-gradient subsampling on sampling efficiency. We illustrate the methodology using data from an empirical study on mental well-being. Finally, we discuss the advantages and challenges when using PDMP samplers for Bayesian variable selection.

**整体含义**——论文提出以**PDMP（分段确定性马尔可夫过程）连续时间采样器**作为替代方案，用于尖-板（spike-and-slab）先验下的贝叶斯变量选择。其核心优势在于：

- 参数沿确定性轨迹连续演化，当一个参数进入或离开模型时其他参数仍持续运动，这对存在强相关参数的后验探索天然有利；
- 可借助无偏随机梯度子采样（stochastic gradients）降低分解型似然模型的计算成本；
- 可扩展至更丰富的统计依赖先验结构。

**目标模型领域**——论文聚焦于心理测量中两类典型的“高维变量选择”问题：

- **随机截距交叉滞后面板模型（RI-CLPM）**：交叉滞后效应数量随变量数二次增长；
- **序数马尔可夫随机场（OMRF）**：网络模型中的边数二次增长。

## 二、提出的方法论

论文的方法贡献可拆分为三层：

### 1. 巩固基础：粘性 PDMP 采样框架

- 将尖-板变量选择嵌入连续时间 PDMP：
  - 活跃参数（系数进入模型）沿确定性轨迹演化；
  - 不活跃参数固定在零值（spike）位置不演化；
  - “粘性事件（sticky events）”控制参数在零处被释放（unfreezing）或到达零时移除。
- 关键思想：
  - **当参数轨迹自然穿过零时**发生从活跃到不活跃的转变，无需取近似决策；
  - **从不活跃转为活跃**依靠随机“解冻”事件，其速率由相邻模型的先验质量比和 slab 在零处的条件密度共同决定。

### 2. 核心贡献一：将粘性 PDMP 拓展到**依赖先验**

传统粘性 PDMP 只支持独立乘积型尖-板先验，论文将其推广到：

- **依赖模型先验**：纳入模型大小先验，如 Beta–Bernoulli（Beta−二项）先验，实现多重性校正；相邻模型概率比仅依赖当前活跃模型大小，其结构沿确定性段保持常数，便于模拟事件。
- **高斯尺度混合 slab**：允许被包含系数之间存在共享尺度参数导致的依赖；引入高斯条件边缘化给出关键公式：
  - 对高斯 slab，排除系数在零处的条件边际密度通过高斯条件分布获得：
    - 条件均值：\(m_i = \mu_i + \Sigma_{iA}\Sigma_{AA}^{-1}(\theta_A - \mu_A)\)
    - 条件方差：\(s_i^2 = \Sigma_{ii} - \Sigma_{iA}\Sigma_{AA}^{-1}\Sigma_{Ai}\)
    - 边界密度：\(f_i(0|\theta_A,\psi) = \frac{1}{s_i}\phi(m_i/s_i)\)
  - 多个排除系数的解冻速率可合并为一簇泊松过程的聚合，再按加权概率抽样选出具体激活参数。
- 论文给出通用的相邻模型先验比率和条件 slab 密度表达：
\[
\kappa_i = C_v \cdot \rho_i(A) \cdot f_i(0|\theta_A,\psi),
\]
其中 \(C_v = E|V_i|\) 为速度均值。

### 3. 核心贡献二：无偏随机梯度的子采样

- 当似然分解为多个因子（如 OMRF 中个体–节点级伪似然）时，引入无偏梯度估计：
\[
\hat{\nabla}U(\theta) = \nabla U_{prior}(\theta) + \frac{1}{m}\sum_b \frac{g_{J_b}(\theta)}{\pi_{J_b}}
\]
- **关键论证**：仅梯度的无偏性不足以保证 PDMP 保持稳态；必须构建与随机事件率匹配的事件时间模拟机制，以保留目标分布。该论点为 BPS、ZigZag 和 Boomerang 各自设计对应的子采样事件率结构。

### 4. 实现方式

- R 包 + Julia 包组合实现，模型通过 Stan/BridgeStan 完成梯度和似然评估；
- 事件时间模拟采用网格自适应/数值积分（非传统上界方法）。

## 六、主要结论与发现

1. **RI-CLPM 中 PDMP 大幅领先传统 RJMCMC**：
   - BPS 与 Boomerang 的中位采样效率（ESS/s）约 38.1 与 35.7，高于 ZigZag 的 8.66 和 NIMBLE 的 3.02；
   - NIMBLE 的效率随样本量增加迅速下降（N=100 时为 7.89，N=300 时降至 1.58），而 PDMP 受样本量影响很小；
   - 结构恢复在 N=300 时达到理想状态（AUC 中位数=1.00，特异性=1.00）；
   - 三种 PDMP 与 NIMBLE 后验包含概率差异中位数不超过 0.03，后验均值差异不超过 0.004，说明它们基本收敛到同一目标分布。

2. **依赖先验的作用**：
   - 在无效应条件下显著降低后验模型大小（如 N=100 时，后验模型规模从 0.93 降低到 0.38）；
   - 但在低样本量非零效应条件中会降低平衡准确度；在 N=300 时差异缩小。

3. **OMRF 子采样效率不一**：
   - BPS：子采样相对全梯度的 ESS/s 比值 2.90/2.52/2.34（p=10/20/30），增益显著；
   - ZigZag：比值 4.35/2.93/2.10，前中规模增益极明显；
   - **Boomerang**：子采样比例 1.00/0.95/0.54——无明显收益甚至拖累；原因为事件率模拟成本增加超过有效样本增长（采样时间由42s增至208s），是事件时间实现相关而非子采样原理缺陷；
   - 子采样未显著改变结构恢复结果。

4. **实证案例**：
   - OMRF 在精神健康指标上支持偏密网络而非强稀疏网络——所有91条边包含概率均>0.50，后验期望模型规模为 85.3，65条边 PIP ≥ 0.95、60条边的 95% 置信区间排除零；
   - 最大后验均值关联为幸福感↔满意度（0.75）。

5. **总体判断**：PDMP 变量选择不彻底取代现有 MCMC，但在模型几何、先验结构、似然分解可被利用时，为强相关高维变量的贝叶斯选择提供了高效、可扩展且实用的新路径。

## 七、优点

论文的方法和实验设计存在多个突出优点：

1. **方法普适性强**：提出统一的“相邻模型先验比 × 条件 slab 密度”框架，并不局限于单一的模型结构，可嵌入 Beta-Bernoulli 模型先验与高斯尺度混合 slab 两类重要依赖先验；
2. **允许子采样而不改变目标分布**：并非仅用随机梯度替代精确梯度，而是讨论了事件率与事件时间模拟在稳态分布保持中的必要性，为后续子采样 PDMP 提供理论严谨范本；
3. **模拟维度设计合理**：RI-CLPM 与 OMRF 各承担不同的计算特征（固定维充分统计量 vs 可分解似然），使结论能够分离“动力学差异”与“梯度子采样差异”两个维度造成的效果差异；
4. **实现可复现**：提供了 R 与 Julia 双语言开源包，并借 BridgeStan/Stan 连接主流概率编程生态；
5. **实证场景与现实数据紧密连接**：借助精神健康 LISS 面板数据展示了方法在真实、非稀疏后验场景中的适用性，避免了仅限模拟虚设环境的局限。

## 八、不足与局限

1. **依赖先验推广并不完全通用**：
   - 并非所有依赖 slab 分布都能给出方便处理的相邻模型密度或变量间边界率，算法适用范围集中在“高斯型/尺度混合”类构建；
   - 故论文只是**将粘性 PDMP 扩展到一类实用结构化先验**，而不是提供“对任意尖-板先验的自动解”。

2. **梯度子采样高度依赖模型结构**：
   - 子采样需要先对似然做因子分解，再设计对应事件时间模拟和事件率上界；无法像 Stan 软件那样通过通用自动微分即插即用；
   - 目前这仍是高度模型定制化的机制，限制了其作为通用推理工具的被接受度。

3. **PDMP 与离散时间 MCMC 的效率比较存在表现尺度歧义**：
   - 离散 MCMC 的 ESS 基于自相关，而 PDMP 连续路径不能直接沿用；ESS/s 虽实用可比，但并不提供一种完全一致的“无表示偏差”比较尺度；
   - 论文亦承认实现环境差异不可简单剥离。

4. **OMRF 后验一致性存在未解释分歧**：
   - 全梯度与子抽样的后验包含概率差异中位数 0.108–0.167，与 NIMBLE 的差异甚至达 0.140–0.424；
   - 该差异并未被蒙特卡洛不确定性完全解释，作者亦未提供最终结论性解释，影响 OMRF 部分实验结果的可信度。

5. **贝叶斯推断中伪似然近似未被消除**：
   - OMRF 中使用的伪似然替代完整似然是一个固有近似；PDMP 仅是保真“伪后验”的采样机制，并不能缓解伪似然与真实后验间的偏差。

6. **可扩展性尚未充分展示**：
   - RI-CLPM 模拟仅覆盖 p=4 变量（12个可选项）；OMRF 最大仅 p=30 节点（435条边），对于论文反复强调的超高维心理测量场景，更高维或更大样本量的结果仍然缺乏。
