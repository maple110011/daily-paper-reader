## 摘要
摊销推断承诺快速测试时的贝叶斯推断，但现有方法本质上是与固定模型绑定的。将摊销扩展到未见过的模型通常需要重新训练或代价高昂的测试时微调。在本文中，我们提出一个问题：是否可能构建一个能够跨不同先验、似然和维度泛化的单一推断网络？我们引入了摊销因子推断网络（AFINs），这是一类基于维度无关模块的编码-合并-解码推断网络，将模型规格及其观测映射到变分后验的参数。实验表明，单个训练好的AFIN在达到与NUTS和几种变分推断方法相当的后验精度的同时，所需的测试时计算量减少了2到4个数量级。代码可在https://github.com/joohwanko/AFINs获取。

## Abstract
Amortized inference promises fast test-time Bayesian inference, but existing methods are inherently tied to fixed models. Extending amortization to unseen models typically requires retraining or costly test-time finetuning. In this paper, we ask: is it possible to build a single inference network capable of generalizing across varying priors, likelihoods, and dimensionality? We introduce Amortized Factor Inference Networks (AFINs), a family of encode-merge-decode inference networks built on dimension-independent modules that map a model specification and its observations to the parameters of a variational posterior. Experimentally, a single trained AFIN achieves posterior accuracy comparable to NUTS and several variational inference methods, while requiring 2 to 4 orders of magnitude less test-time compute. Code is available at https://github.com/joohwanko/AFINs.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：提出**摊销因子推断网络（AFIN）**，采用**编码‑合并‑解码（encode‑merge‑decode）**架构。受共轭指数族更新的启发，将贝叶斯推断视为：独立编码每个因子（先验和观测似然）→合并所有因子的信息→解码出变分后验参数。AFIN通过**维度无关模块**（BoxMLP、BoxTransformer）实现该流程，使网络参数形状不受潜在变量维度$d$影响，同时输出对维度索引置换等变。
- **关键技术细节**：
  - **维度无关模块**：
    - **BoxMLP**：通过参数绑定，每个维度的特征由局部输入和全局池化（如均值）的线性组合得到，在保持置换等变的同时消除了对$d$的参数依赖。
    - **BoxTransformer**：在标准Transformer基础上，将注意力中的query、key、value和FFN替换为BoxMLP，使得令牌（因子）的节点/对嵌入在因子轴上做注意力，而每个令牌内部仍保持维度索引，因此参数形状与$d$无关。
  - **AFIN完整流程（Algorithm 1）**：
    1. **编码**：对每个因子（前n=0的prior，n=1..N的likelihood），先通过类型特定的适配器（adapter）$a_{t_n}$将原始参数和观测转换为初步张量，再经共享的BoxMLP编码器$b_{\text{enc}}$得到节点‑对嵌入$E_n^{(0)}$（节点$\in\mathbb{R}^{d\times C}$，对$\in\mathbb{R}^{d\times d\times C}$）。
    2. **合并**：依次通过$M$个BoxTransformer块$T_m$，在因子轴上执行注意力，交互更新所有因子的嵌入。
    3. **解码**：将所有因子的最终嵌入沿因子轴求和池化，得到任务级嵌入$\bar{E}$，再经由BoxMLP解码器$b_{\text{dec}}$输出变分参数$\phi$（如高斯均值、精度，或流的参数）。
  - **训练目标**：最大化为模拟任务中从联合模型采样的$(z,y)$分配的条件对数密度$\mathbb{E}[\frac{1}{d}\log q_{f_w(t,\theta,y)}(z)]$，等价于最小化前向KL散度。这一目标使得近似分布更适合作为重要性采样（SNIS）的提议分布。
  - **测试时**：直接前向得到$\phi$，可输出样本或进行自归一化重要性采样修正。

- **主要结论**：单一AFIN网络可在零样本情况下，对**不同先验族、似然族、维度和观测数量**的后验推断任务，取得与NUTS和多种变分推断方法**相当甚至更优的精度**，同时测试时计算量减少**2‑4个数量级**（单次前向仅数毫秒）。当作为SNIS提议时，能进一步逼近NUTS精度，且远快于同等精度的迭代方法。
- **关键发现**：
  - 前向KL训练使AFIN后验具有良好覆盖率，适合重要性采样修正。
  - 维度无关的BoxMLP/BoxTransformer设计成功实现了跨维度泛化。
  - 在维度外推中最具挑战，但在观测数外推和联合外推中表现强劲。
  - 流解码器可在相同骨干上进一步提升精度，但采样时间略有增加。

### 7. 优点

- **方法创新**：首次提出维度无关的编码‑合并‑解码架构，使一个网络能处理模型族级别的变分推断；BoxMLP和BoxTransformer实现了参数形状与$d$解耦的置换等变映射。
- **泛化性强**：训练仅基于模拟生成的任务，即可零样本迁移到真实数据和未见过维度/数据量，体现强泛化能力。
- **效率极高**：测试时前向传播极快（毫秒级），且可作为高效SNIS提议在不增加太多计算下提升精度，显著优于需迭代优化的VI和MCMC。
- **实验充分**：从合成控制到真实数据，从内推到外推，从点估计到分布比较，对比多种强基线，并给出计算‑精度曲线和诊断指标，分析全面且公平。

### 8. 不足与局限

- **因子类型预定义**：AFIN要求预先定义所有可能的因子类型（prior和likelihood）并训练对应的适配器；引入新型因子需要设计适配器并微调，虽然比从头训练轻量，但仍需额外工作。
- **表示能力受限**：当前节点‑对接口不能直接表示任意概率程序结构（如确定性变换、复杂层次模型、控制流），且对偶表示复杂度为$O(d^2)$，对高维（$d>大约50）扩展性不足。
- **外推挑战**：在纯维度外推（$d$超出训练范围）中，AFIN+SNIS的误差高于短时NUTS，说明高维泛化仍需改进。
- **与专用基线差距**：在OpenML分类的后验预测上，AFIN在AUC和NLL上略逊于TabPFN，说明对数据预测任务可能不如专门设计的自回归模型；但AFIN目标不是分类，而是通用后验推断。
- **训练分布设计**：合成任务生成依赖于手工设计的采样分布（维度、数据量、参数先验），可能未完全覆盖真实任务的长尾分布，导致某些真实场景表现可能不如预期。
