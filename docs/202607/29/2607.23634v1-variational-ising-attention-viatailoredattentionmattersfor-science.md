## 摘要
注意力机制通过带有softmax归一化的查询-键评分实现上下文建模。受工业界长上下文需求的驱动，主流研究倾向于稀疏性与高效性——然而softmax的独立性假设始终存在。但对于不受长标记约束的科学任务而言，更丰富的结构化耦合往往至关重要，使得定制化注意力既可行又更为恰当。为此，我们提出变分伊辛注意力（VIA），它通过引入相互作用的伊辛模型增强softmax归一化；注意力模式通过变分平均场推断从可学习的成对耦合中涌现，将注意力从孤立项的排名重新定义为交互实体的集体状态。我们在逆合成反应中心预测任务上实例化VIA，该任务内在地受合作键断裂约束的支配。跨模型变体的综合实验结合机理分析表明，VIA始终显著优于标准softmax注意力。更广泛而言，我们的发现表明，对于科学问题，最优解并非通用高效性，而是与内在领域结构相一致的定制化注意力。本工作为该范式提供了理论扎实且经验验证的实例。

## Abstract
Attention enables context modeling via query-key scoring with softmax normalization. Driven by industrial long-context demands, mainstream research has converged toward sparsity and efficiency--yet softmax's independence assumption persists. For scientific tasks unburdened by long-token constraints, however, richer structured coupling may often be essential, making tailored attention both viable and more appropriate. To this end, we propose Variational-Ising-Attention (VIA), which augments softmax normalization with an interacting Ising model; attention patterns emerge from learnable pairwise couplings via variational mean-field inference, redefining attention from a ranking over isolated items to a collective state over interacting entities. We instantiate VIA on retrosynthesis reaction center prediction, a task inherently governed by cooperative bond-breaking constraints. Comprehensive experiments across model variants, coupled with mechanistic analyses, demonstrate that VIA consistently and substantially outperforms standard softmax attention. More broadly, our findings suggest that for scientific problems, the optimal solution is not general-purpose efficiency, but appropriately tailored attention aligned with intrinsic domain structure. This work provides a theoretically grounded and empirically validated instantiation of this paradigm.

- **背景**：标准 softmax 注意力假设查询-键得分相互独立，适用于工业界的长上下文稀疏化需求。但在科学任务中（如化学反应中心预测），实体间存在结构化耦合（合作/竞争），这种独立性假设限制了建模能力。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：将注意力重新定义为交互实体的集体状态。引入伊辛模型，用可学习的成对耦合矩阵 \(J\) 刻画位置间的协同/竞争，通过变分平均场推断得到注意力权重。
- **技术细节**：
  - 定义每个位置 j 的自旋变量 \(s_j \in \{-1, +1\}\)，能量函数为：
    \[
    E(s) = -\sum_j h_j s_j - \frac12 \sum_{j \neq k} J_{jk} s_j s_k
    \]
    其中 \(h_j\) 来源于标准 softmax 的查询-键得分，\(J\) 为可学习成对耦合。
  - 使用变分平均场推断近似边缘概率 \(m_j = p(s_j = +1)\)：
    1. 初始化 \(m^{(0)}_j = \text{softmax}_j(h_j / T)\)
    2. 迭代 K 步（本文取 K = 1 已收敛）：
       \[
       \tilde{m}^{(t)}_j = \text{softmax}_j\left( \frac{h_j + \gamma \sum_{k\neq j} J_{jk} m^{(t-1)}_k}{T} \right)
       \]
       \[
       m^{(t)}_j = \lambda m^{(t-1)}_j + (1 - \lambda) \tilde{m}^{(t)}_j
       \]
    3. 最终注意力权重 \(\alpha_{ij} = m_j^{(K)}\)，再经第二次耦合构造最终注意力场。
- **耦合矩阵参数化**：四种变体——Original（全秩）、LowRank（低秩分解 \(J = UU^\top\)，固定秩64）、Hyper（超网络生成输入条件化耦合）、PairMLP（每对位置独立 MLP）。
- **部署策略**：
  - **V4（终端部署）**：softmax 编码器 + 单层终端 VIA 头。
  - **V10（骨干部署）**：所有编码器层全部替换为 VIA。

## 6. 主要结论与发现

- **核心结论**：VIA 骨干部署（V10）大幅超越标准 softmax 和终端部署（V4）。最佳变体 V10-LowRank 测试集精确匹配准确率达 **94.90%**，而 softmax 基线仅为 77.54%～79.5%。

- **机制解释**：
  - 骨干部署极大降低几何挫折（V10-Original 降至 8.22×10⁻⁶），使能量景观平滑。

- **收敛性**：单次平均场迭代（K=1）即达到不动点，说明 J 矩阵条件良好。
- **总体意义**：结构化耦合嵌入**特征提取全过程**（骨干）比仅用于预测头（终端）更关键；为科学任务定制注意力比通用高效注意力更有效。
