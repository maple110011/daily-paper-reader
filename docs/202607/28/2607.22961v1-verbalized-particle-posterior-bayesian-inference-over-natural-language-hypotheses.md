## 摘要
语言化机器学习（VML）将模型参数化为一个自然语言提示，由大语言模型评估为f(x;θ)。该框架是可解释的，但它只承诺单一假设，没有不确定性度量，且该假设在相同数据的多次优化运行中差异很大。我们提出语言化粒子后验（VPP），将语言化学习视为贝叶斯推断问题：维护一个自然语言假设的群体作为粒子，使用Metropolis-Hastings（VPP-MH）或序贯蒙特卡洛（VPP-SMC）更新它们，并通过贝叶斯模型平均进行预测。两种算法都将大语言模型视为黑箱，无需访问logits或梯度。这带来了一个独特的后果：在经典贝叶斯学习中，模型选择位于后验之外；而在VPP中，模型结构和参数共享同一语言空间，后验覆盖两者。我们在回归、分类和规则发现基准上评估了VPP。它在每个基准上都优于单次VML运行，并且在大多数基准上匹配或超过独立VML运行的最佳集成，同时消除了VML偶尔产生的灾难性单次运行失败。由于每个粒子都是人类可读的假设，后验本身可供读者检查，以纯文本形式看到数据支持哪些解释、排除了哪些解释。

## Abstract
Verbalized Machine Learning (VML) parameterizes a model as a natural-language prompt that an LLM evaluates as f(x; theta). The framework is interpretable, but it commits to a single hypothesis with no measure of uncertainty, and that hypothesis varies substantially across optimization runs on the same data. We propose the Verbalized Particle Posterior (VPP), which treats verbalized learning as a Bayesian inference problem: maintain a population of natural-language hypotheses as particles, update them with Metropolis-Hastings (VPP-MH) or Sequential Monte Carlo (VPP-SMC), and predict by Bayesian model averaging. Both algorithms treat the LLM as a black box, requiring no access to logits or gradients. A distinctive consequence follows. In classical Bayesian learning, model selection sits outside the posterior; in VPP both model structure and parameters share a single language space, and the posterior ranges over both. We evaluate VPP on regression, classification, and rule-discovery benchmarks. It improves over a single VML run on every benchmark and matches or exceeds an oracle-best ensemble of independent VML runs on most, while eliminating the catastrophic single-run failures that VML occasionally produces. Because each particle is a human-readable hypothesis, the posterior is itself something a reader can inspect, seeing in plain text which explanations the data supported and which it ruled out.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：Verbalized Machine Learning (VML) 将模型参数化为一个自然语言提示（prompt），由LLM作为函数f(x;θ)进行评估。虽然VML具有可解释性、能自动发现模型结构、接受先验知识等优点，但它存在两个根本缺陷：
  - **缺乏不确定性度量**：VML只返回单个假设θ*，无法量化预测的不确定性。
  - **优化结果不稳定**：由于优化器LLM在大离散空间中的随机性，同一数据上不同运行得到的假设差异巨大。例如在线性回归任务上，15次独立VML运行的测试MSE范围从1.08到48.30，跨度达44.7倍；在contains-zero任务上，单次运行准确率从32%到100%。并且VML无法检测自身失败，因为没有任何机制来标记不可靠的输入。

- **研究动机**：贝叶斯后验p(θ|D)是标准解决方案：维持一个分布而非单一弱支持的假设。但将贝叶斯应用于VML面临双重挑战：
  - 参数空间Θ_language是离散、组合的，没有梯度或连续邻域，大多数现代后验推断方法不可用。
  - 在经典贝叶斯学习中，模型选择在后验之外；而在VML中，模型结构和参数共享同一语言空间，因此单一后验可同时选择模型和推断参数——这是经典MCMC无法自然表达的目标。

- **整体含义**：论文提出Verbalized Particle Posterior (VPP)，一种基于粒子的框架，用于对语言化假设进行贝叶斯推断。VPP维护K个自然语言假设粒子，通过黑箱算法更新，并用贝叶斯模型平均进行预测。每个粒子都是人类可读的，因此后验本身可被检查。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 核心思想
- 将语言化学习视为贝叶斯推断问题：维护一个自然语言假设的粒子集合{(θ^{(k)}, w_k)}，其中每个θ^{(k)}是一个完整的自然语言假设，w_k是其权重。
- 预测时通过贝叶斯模型平均（BMA）整合：回归用加权平均，分类用加权多数投票。
- 两种实例化算法：VPP-MH（Metropolis-Hastings）和VPP-SMC（Sequential Monte Carlo）。两者均将LLM视为黑箱，无需访问logits或梯度。

### 关键技术细节

#### 似然函数
- 回归：使用均方误差负对数似然，含τ=1的温度参数。
- 分类：使用平滑的0-1似然，ϵ=0.05防止单个误分类导致无限大的对数似然比。
- 似然基于LLM对输入的预测结果计算，因此任何能产生预测的LLM均可接入。

#### 先验
- p(θ)由LLM在模型类无关种子提示下的生成分布隐式定义。点评估不可行，因此仅从先验采样。
- 初始粒子通过在不同采样温度下运行优化器LLM K次产生，视为先验的信息样本。

#### VPP-MH（算法1）
- **提议分布**：使用优化器LLM本身：给定当前假设θ^{(k)}和迷你批次，生成候选˜θ^{(k)}。这是信息丰富的提议，比随机扰动更高效。
- **接受/拒绝步骤**：与标准MH不同，由于无法点评估LLM生成密度（先验概率和提议概率），接受率仅包含似然比：
  α = min(1, p(D_batch|˜θ^{(k)}) / p(D_batch|θ^{(k)}))
  这打破了详细平衡，但经验证明拒绝步骤是关键。
- **流程**：每个粒子在每个训练步骤执行：前向传播 → 提议 → 评估提议 → 接受/拒绝。
- **每步LLM调用次数**：3K（前向、提议、提议评估各一次）。粒子权重保持均匀，不使用ESS监控。

#### VPP-SMC（算法2）
- **解决VPP-MH的两个局限**：
  1. 随着粒子改进，接受率下降（难以进一步改善），导致停滞。
  2. 所有粒子在BMA中权重相等，少数差粒子会降低整体性能。
- **三大修改**：
  1. **温度重要性权重**：使用线性退火β: 10→1，扁平权重促进探索，尖锐权重集中于最优假设。pragmatic reweighting，非正式SMC采样器。
  2. **累积评估缓冲区**：在最近B=40个数据点（4个批次）上计算似然，而非单一批次，减少噪声。
  3. **自适应变异**：重采样后，根据粒子在缓冲区上的对数似然与中位数比较，调整优化器采样温度：高于中位数用低温（保守优化），低于中位数用高温（探索性变异）。
- **重采样**：当有效样本大小ESS < K/2时触发，使用系统重采样。
- **每步操作**：累积缓冲区 → 计算权重 → 检查ESS并重采样 → 自适应变异。

## 6. 论文的主要结论与发现
- **VPP在所有7个基准上均优于单次VML**。
- **VPP匹配或超过VML×5 oracle最佳** 在7个任务中的6个上（例外：two-blobs略低）。
- **VPP消除了VML的灾难性失败**：如linear regression上VML单次MSE可从1.08到48.30，而VPP-MH仅0.47-1.86。
- **VPP-SMC达到100%准确率** 在two-circles、sum parity、contains-zero的所有种子上；而单次VML在这些任务上波动大（如sum parity上65%-100%）。
- **接受/拒绝步骤是关键**：消融实验显示，去掉拒绝步骤后sum parity准确率下降22.2pp，linear MSE翻倍。
- **VPP-SMC比VPP-MH更适合非线性与符号任务**，推荐SMC作为默认。
- **不确定性量化**：通过粒子分歧提供“我不知道”信号，标准VML不具备。

## 8. 不足与局限
- **实验覆盖有限**：
  - 仅使用单一LLM（Llama-3-70B-Instruct），未验证其他模型（如GPT-4、Claude）的泛化性。

  - 接受率仅用似然比，舍弃先验比和提议比，破坏详细平衡。算法只是“实用MCMC-like”，理论上不保证收敛到精确后验。

- **未探索变体**：
  - 未尝试其他MCMC方法（如吉布斯采样）、不同LLM作为提议、更复杂的退火方案。
