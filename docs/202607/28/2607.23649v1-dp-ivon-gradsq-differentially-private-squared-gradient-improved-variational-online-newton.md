## 摘要
差分隐私为在敏感数据上训练神经网络提供了正式的隐私保证，而贝叶斯深度学习为不确定性感知预测提供了原则性框架。结合这两个目标仍具挑战性，因为隐私噪声可能与贝叶斯后验采样引入的随机性相互作用。在这项工作中，我们通过改进变分在线牛顿（IVON）优化器研究差分隐私变分贝叶斯学习。我们引入了DP-IVON-Gradsq，即IVON的隐私变体。所提出的方法使用噪声校正的平方梯度估计器从私有化梯度构建曲率估计，减少了后验采样噪声与隐私噪声之间的直接交互，同时保留了IVON类似Adam的计算效率。我们在CIFAR-10上，针对一系列隐私预算，将DP-IVON-Gradsq与标准隐私优化器DP-SGD和DP-Adam进行了比较。结果表明，DP-IVON-Gradsq在弱到中等隐私约束下（即ε较大到中等值）具有竞争力，而在强隐私下性能下降。代码可在https://github.com/NourJamoussi/DP-IVON-Gradsq.git获取。

## Abstract
Differential privacy provides formal privacy guarantees for training neural networks on sensitive data, while Bayesian deep learning offers a principled framework for uncertainty-aware prediction. Combining these two objectives remains challenging, as privacy noise can interact with the stochasticity introduced by Bayesian posterior sampling. In this work, we investigate differentially private variational Bayesian learning through the Improved Variational Online Newton (IVON) optimizer. We introduce DP-IVON-Gradsq, a private variant of IVON. The proposed method constructs its curvature estimate from the privatized gradient using a noise-corrected squared-gradient estimator, reducing the direct interaction between posterior-sampling noise and privacy noise while preserving the Adam-like computational efficiency of IVON. We evaluate DP-IVON-Gradsq on CIFAR-10 against the standard private optimizers DP-SGD and DP-Adam over a range of privacy budgets. The results show that DP-IVON-Gradsq is competitive under weak-to-moderate privacy constraints, i.e., large-to-moderate values of $\varepsilon$, while degrading under strong privacy. Code is available at https://github.com/NourJamoussi/DP-IVON-Gradsq.git.

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- 基于改进变分在线牛顿（IVON）优化器，引入一个**噪声校正的平方梯度估计器**来构建曲率（Hessian近似），从而减少后验采样噪声与隐私注入噪声的直接交互，同时保留IVON类似Adam的计算效率。

### 关键技术细节
- **IVON回顾**：IVON维护一个高斯后验 \( q(\theta) = \mathcal{N}(m, \text{diag}(\sigma_v^2)) \)，其中方差由曲率估计 \( h \) 参数化：\( \sigma_v^2 = 1 / (N_{\text{ess}} (h + \delta_v)) \)。每步采样参数 \( \theta \sim q \)，计算梯度，更新 \( m \) 和 \( h \)。
- **差异化隐私处理**：
    1. 对每个样本计算梯度 \( g_i \)。
    2. 用 \( \ell_2 \) 范数裁剪：\( \bar{g}_i = g_i \min(1, C / (\|g_i\|_2 + \varepsilon_{\text{num}})) \)。
    3. 加高斯噪声得到平均私有梯度：\( g_{\text{ dp }} = \frac{1}{b} \sum_i \bar{g}_i + \xi, \xi \sim \mathcal{N}(0, \frac{\sigma_p^2 C^2}{b^2} I) \)。
- **噪声校正平方梯度估计**（规避噪声与采样噪声耦合）：
    - 不使用原始IVON的曲率估计 \( \hat{h}_{\text{IVON}} = g_{\text{ dp }} \odot \frac{\theta - m}{\sigma_v^2} \)（该式直接依赖采样扰动）。
    - 改用：\( \hat{v} = \max\left( g_{\text{ dp }}^2 - \frac{\sigma_p^2 C^2}{b^2},\ 0 \right) \) （元素级）。
    - 然后曲率目标：\( \hat{h} = N_{\text{ess}} \hat{v} \)。
    - 注意：减去的项是已知的隐私噪声方差；最大投影确保非负。该操作仅使用私有梯度 \( g_{\text{ dp }} \)，不消耗额外隐私预算。
- **更新规则**（与IVON一致）：
    - 曲率动量更新：\( h \leftarrow \beta_2 h + (1-\beta_2)\hat{h} + \frac{(1-\beta_2)^2 (h - \hat{h})^2}{2(h + \delta_v)} \)。
    - 梯度动量：\( s \leftarrow \beta_1 s + (1-\beta_1) g_{\text{ dp }} \)；去偏：\( \bar{s} = s / (1 - \beta_1^t) \)。
    - 后验均值更新（自然梯度风格）：\( m \leftarrow m - \alpha \frac{\bar{s} + \delta_v m}{h + \delta_v} \)。
    - 后验方差更新：\( \sigma_v^2 \leftarrow 1 / (N_{\text{ess}} (h + \delta_v)) \)。
- **隐私核算**：使用RDP Accounting，基于采样率 \( q = b/|D| \)、步数 \( T \)、噪声乘子 \( \sigma_p \)、目标 \( \delta_p \) 计算最终隐私预算 \( \varepsilon \)。
