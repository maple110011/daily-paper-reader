# Adaptive Score-Based VAMP: Self-Tuning Hyperparameters via Tilted EM 

Siqi Na and Tadashi Wadayama 

Department of Computer Science, Nagoya Institute of Technology, Nagoya, Japan E-mail: {nasiqi, wadayama }@nitech.ac.jp 

Abstract —Approximate-message-passing methods offer fast Bayesian inference for high-dimensional inverse problems, but their performance and state-evolution predictions rely on cor-rectly specified module parameters. This paper develops an adaptive version of score-based vector approximate message passing (SC-VAMP). Each parameterized factor is updated by a local tilted expectation–maximization (EM) step that reuses the tilted moments already computed by the single-input single-output module interface. Under standard large-system state-evolution assumptions and identifiability conditions, the matched parameters form a Bayes-optimal population fixed point of the adaptive recursion. The argument is written separately for prior modules and likelihood/LMMSE modules, the latter using the Gaussian cavity induced by the VAMP transformed-error model. Numerical results for linear and one-bit Bernoulli–Gaussian compressed sensing show that the proposed updates recover near-oracle performance from strongly mismatched initializations. 

Index Terms —Vector approximate message passing, expectation–maximization, hyperparameter estimation, compressed sensing, one-bit quantization. 

I. I NTRODUCTION 

Compressed sensing (CS) showed that a high-dimensional sparse signal can be recovered from far fewer noisy linear measurements than its ambient dimension [1], [2]. Its influence extends well beyond the original sparse-recovery setting: many imaging, communications, array-processing, and quantized-sensing problems can be formulated as the estimation of a structured random vector from linear or nonlinear measure-ments. The resulting inference problems are high-dimensional, often nonlinear, and strongly dependent on both the sensing operator and the statistical structure of the unknown signal. Approximate message passing (AMP) and its descendants provide a computationally efficient route to high-dimensional Bayesian inference. AMP was developed for large i.i.d. sens-ing matrices and admits a scalar state evolution (SE) that tracks its mean-squared error [3]. Generalized AMP (GAMP) ex-tends the same message-passing principle to generalized linear models with separable input and output channels, covering nonlinear likelihoods such as quantization or bounded noise [4]. Vector approximate message passing (VAMP) extends SE-predictable inference in a different direction: it handles the important class of right-rotationally invariant (RRI) matrices by pairing a nonlinear denoising module with a linear mini-mum mean-square error (LMMSE) module [5]. This extension is important for inverse problems with ill-conditioned or structured sensing operators, where standard AMP/GAMP can be fragile [6]. Score-based VAMP (SC-VAMP) further abstracts the VAMP mechanism into a modular single-input single-output (SISO) interface [7]. Each module communicates a mean and variance through score-based identities, so a larger factor graph can be assembled from explicit prior, likelihood, and coupling factors while retaining the VAMP-style Onsager correction. Notably, an SC-VAMP module does not need explicit parameter knowl-edge per se: all statistical structure enters through its score function, which may even be learned from data. In signal processing, however—and in CS in particular—this option is rarely available for the signal prior: x is precisely the quantity to be estimated, so samples of x from which a score could be learned are not at hand, and the prior must instead be specified as an explicit parametric family whose hyperparameters, such as sparsity rates and component variances, are unknown in advance, as is the noise level. Mismatch in these quantities leads to large reconstruction errors even when the inference architecture itself is appropriate. In Bernoulli–Gaussian (BG) sparse recovery, for example, a wrong sparsity rate, active variance, or noise variance changes the tilted distributions and Onsager terms, raises the fixed-point MSE, and invalidates matched-SE predictions [8]. Learning unknown parameters inside message passing has a long history. EM-GAMP learns mixture priors and noise levels in generalized linear models [9]. EM-VAMP and adaptive VAMP provide EM learning rules and consistency results for linear RRI systems [10], [11]. EM-GVAMP extends EM-based tuning to generalized VAMP with nonlinear output channels [12]. A different line of work uses risk estimates such as Stein’s unbiased risk estimate (SURE) to select de-noiser parameters within AMP [13]. These methods show that parameter adaptation is effective, but the corresponding M-steps are usually derived for a fixed algorithmic architecture or a specific pair of input/output modules. For SC-VAMP, the missing piece is a module-local rule that updates each explicit factor while leaving the SISO score interface and Onsager correction untouched. This paper develops a factor-level adaptive mechanism for SC-VAMP. For each parameterized module, we attach a local tilted expectation–maximization (EM) step to the explicit factor used by that module. The update reuses the tilted distribution and moments already computed by the SC-VAMP SISO rule, so the score-based interface and Onsager correction are left unchanged. Under standard large-system SE assumptions and identifiability conditions, we identify arXiv:2607.14597v1 [eess.SP] 16 Jul 2026 a Bayes-optimal population fixed point: the true hyperpa-rameters together with the matched SE variance are left invariant by the adaptive recursion. The proof separates prior modules from likelihood/LMMSE modules, because the latter are naturally analyzed under the Gaussian cavity induced by VAMP’s transformed-error SE. Numerical experiments on linear and one-bit BG CS show that the proposed tilted-EM updates recover near-oracle performance from strongly mismatched initializations, essentially closing the gap to the oracle parameter setting. We compare three variants throughout. The oracle runs SC-VAMP with the true hyperparameters. The adaptive method starts from mismatched hyperparameters and updates them using the proposed tilted-EM steps. The frozen baseline uses the same mismatched initialization as the adaptive method but disables all EM updates, isolating the value of self-tuning. Adaptive SC-VAMP adds a local tilted-EM update to each parameterized factor, reusing the moments already computed by the SISO interface. It preserves the modular mean-variance interface with little overhead, has the true hyperparameters as a Bayes-optimal population fixed point under standard LSL as-sumptions (Proposition 1), and approaches oracle performance on linear and one-bit BG CS from strong mismatch. Future work will target broader factor graphs and learned-score priors, where self-tuning must rely on the tilted moments alone, the explicit factor for the EM M-step being unavailable.
