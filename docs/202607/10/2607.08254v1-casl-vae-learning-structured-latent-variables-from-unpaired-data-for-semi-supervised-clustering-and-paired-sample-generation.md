## 摘要
量化目标人群相对于参考人群的变异性是许多科学和临床问题的核心（例如，患病与健康）。然而，在没有配对数据且存在异质性目标变异的情况下，现有方法难以分离目标特异性变异的多个模式。我们提出CASL-VAE，一种深度对比潜在变量模型，从未配对数据中学习结构化的潜在生成因子。CASL-VAE将变异分解为跨人群共享的连续公共潜在因子和分级显著潜在因子，后者将目标特异性异质性建模为离散亚型和连续亚型内变异。利用变分推断，我们展示了如何使用未配对数据在参考域和目标域上进行近似联合似然优化，为配对样本生成和跨域分析提供了原则性基础。我们在半合成神经影像数据上验证了CASL-VAE，证明与基线聚类和生成模型相比，其亚型恢复和配对样本生成能力有所提升。我们还验证了其揭示阿尔茨海默病中生物学合理的异质性的能力。

## Abstract
Quantifying variability in a target population relative to a reference population is central to many scientific and clinical problems (e.g., diseased vs. healthy). Yet, without paired data and in the presence of heterogeneous target variation, existing methods struggle to separate multiple modes of target-specific variation. We propose \textit{CASL-VAE}, a deep contrastive latent variable model that learns structured latent generative factors from unpaired data. CASL-VAE factorizes variation into continuous common latent factors shared across populations and hierarchical salient latent factors that model target-specific heterogeneity as discrete subtypes and continuous within-subtype variation. Using variational inference, we show how approximate joint likelihood optimization over reference and target domains can be performed using unpaired data, providing a principled basis for paired-sample generation and cross-domain analysis. We validate CASL-VAE on semi-synthetic neuroimaging data, demonstrating improved subtype recovery and paired-sample generation compared to baseline clustering and generative models. We also validate its ability to reveal biologically plausible heterogeneity in Alzheimer's disease.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题**：在许多科学和临床场景中（如疾病 vs. 健康），需要量化目标人群相对于参考人群的变异。然而，**缺乏配对样本**（即无法获得同一受试者两种状态的数据），且目标变异往往具有**异质性**（存在多个亚型或模式），导致现有方法难以分离出干净的目标特异性变异。
- **现有方法的不足**：标准对比分析（CA）方法只能分离共享与目标特异性变异，但无法建模目标域内部的多种模式；聚类方法不利用对比结构，可能受共享噪声干扰；生成模型易将共享与特异性因素纠缠。
- **本文贡献**：提出 **CASL-VAE**，一个深度对比潜变量模型，通过结构化的潜在因子分解，实现从未配对数据中学习共享与目标特异性变异，支持半监督亚型发现和配对样本生成。

## 2. 方法论

### 核心思想
- 将潜在空间分解为：
  - **连续公共潜在变量** \(z\)：刻画参考域和目标域共享的变异（如年龄、扫描仪效应）。
  - **分级显著潜在变量**：包含**离散亚型** \(s_{\text{cat}}\)（categorical，表示目标域中的亚类）和**连续亚内变异** \(s_{\text{cont}}\)（连续，表示亚型内部细微差异）。
- 通过变分推断，利用未配对数据优化近似的联合对数似然。

### 关键技术细节
1. **生成模型**：
   - 先验：\(p(z)=\mathcal{N}(0,I)\), \(p(s_{\text{cat}})=\text{Uniform}\), \(p(s_{\text{cont}}|s_{\text{cat}})=\mathcal{N}(\mu_\psi(s_{\text{cat}}),I)\)（\(\mu_\psi\)为可学习嵌入）。
   - 解码器：目标样本 \(x\) 重建为 \(d_{\theta_z}(z)+d_{\theta_s}(s_{\text{cat}},s_{\text{cont}})\)；参考样本 \(y\) 将显著潜变量固定为非信息的预设值 \(s'\)，重建为 \(d_{\theta_z}(z)+d_{\theta_s}(s')\)。
2. **推理模型（编码器）**：
   - 公共编码器 \(e_{\phi_z}\) 输出 \(q(z|x)\) 或 \(q(z|y)\)。
   - 显著编码器 \(e_{\phi_s}\) 输出离散 logits（通过 Gumbel-Softmax）和连续条件均值。
3. **ELBO 推导**：
   - 假设**后验解耦** \(q(z|x,y)=q(z|x)=q(z|y)\)，联合 ELBO 可分解为两个域的边际 ELBO 之和（式 4），从而可利用未配对样本优化。
4. **正则化项**：
   - **MMD**：对齐 \(q(z|x)\) 与 \(q(z|y)\) 的分布。
   - **样本级潜在一致性**：通过交叉域变换（用 \(z\) 解码出伪参考样本 \(\tilde{y}\)）强制 \(q(z|x)\) 与 \(q(z|\tilde{y})\) 接近。
   - **弱监督 BCE 损失**：利用域标签（参考/目标）防止参考样本被分配为目标亚型。
   - **参考正则化**：对参考样本的 \(s_{\text{cont}}\) 后验和先验施加零均值约束，避免信息泄漏。
5. **目标函数**：
   \[
   J = -L_{\text{ELBO}} + \lambda R_{\text{MMD}} + \eta R_{\text{LC}} + \zeta R_{\text{BCE}} + \gamma R_{\text{ref}}
   \]

### 算法流程（文字描述）
1. 输入目标样本批 \(X\) 和参考样本批 \(Y\)。
2. 通过公共编码器获得 \(z_x, z_y\)。
3. 通过显著编码器为目标样本输出 \(s_{\text{cat},x}\) 和 \(s_{\text{cont},x}\)（参考样本固定为预设值）。
4. 解码重建 \(\hat{x}, \hat{y}\)。
5. 计算 ELBO 项和所有正则化项，反向传播更新所有网络参数（包括先验均值 \(\mu_\psi\)）。
6. 训练时对 Gumbel-Softmax 温度进行退火，最终离散化。

## 3. 实验设计

### 数据集
- **半合成数据**：来自 iSTAGING 联盟的 T1w MRI 数据，提取 145 个 ROI 体积。选用 988 名认知正常（CN）参与者，随机分为参考组（494）和伪目标组（494）。伪目标组进一步分为三个亚型（S1-S3），每个亚型定义独特的萎缩模式（14 个 ROI），萎缩率范围（典型：10-30%；轻度：10-20%；极轻：0-10%；中度：20-30%）。另构建含真实配对伪目标样本的测试集。
- **真实疾病数据**：ADNI 数据集，CN 为参考，MCI 和 AD 为目标。训练：ADNI2/GO（206 参考，660 目标）；测试：ADNI1（227 参考，588 目标）。

### 评价指标
- 亚型发现：调整兰德指数（ARI，越高越好）。
- 重建质量：平均绝对误差（MAE，越低越好）。
- 配对样本生成：生成的参考样本与真实参考样本之间的余弦相似度。

### 对比基线
- **标准聚类**：K-means、GMM。
- **深度聚类**：GMVAE（仅目标域聚类，因不能处理参考域）。
- **半监督聚类**：Smile-GAN（仅目标域聚类）。
- **生成模型**：cVAE（统一潜在空间）、SepVAE（对比 VAE，无分级结构）。
注：对于 cVAE 和 SepVAE，对其潜在表示后接 K-means 以评估聚类。

### 训练配置
- 公共潜在维度 \(k=15\)，连续显著维度 \(t=2\)，离散亚型数 \(M\) 由交叉验证稳定性选取（半合成中 \(M=4\)，真实中 \(M=3\)）。
- 优化器：Adam，学习率 \(1\times 10^{-3}\)，批次大小 128，最大 500 轮。
- 多次（10 次）重复留出交叉验证（80% 训练，20% 验证），报告均值和 95% 置信区间。

## 6. 主要结论与发现
1. **亚型发现**：在典型萎缩率（10-30%）下，CASL-VAE 与最佳基线（Smile-GAN）持平；在轻度（10-20%）下显著优于所有基线。在联合聚类（参考+目标）中，CASL-VAE 始终最优。
2. **配对样本生成**：CASL-VAE 的余弦相似度显著高于 cVAE 和 SepVAE。
3. **可解释性**：学会的原型目标模式（\(\delta_{s_{\text{cat}}}\)）与半合成真值高度吻合，且能可视化连续亚内变异（对应于萎缩率）。
4. **临床应用**：在真实 AD 数据上，推断的偏差指数（DI）与多个临床认知评分、CSF 生物标志物显著相关，说明模型捕获了疾病相关的变异模式。
5. **结构优势**：分级显著潜变量和正则化共同促使模型在弱效应下仍能有效分离亚型，而消融某一正则化则性能下降。
