## 摘要
传感器丰富的数据驱动应用越来越多地使用贝叶斯方法，从噪声传感器测量和物理模型中推断动态系统的潜在状态。然而，似然计算仍然是实现精确后验和高性能推断的关键瓶颈。本文提出了一种贝叶斯滤波技术，该技术利用处理器原生不确定性跟踪进行不确定性传播和推断。该技术通过原生操作实现确定性分层重要性重构，对于以程序代码编写的任意模型，提供确定性延迟和有限内存使用。对三个非线性状态空间系统的基准测试将该方法与粒子滤波器和基于蒙特卡洛的似然估计器进行了比较。该技术实现了确定性近似滤波，在匹配结果质量下，与直接蒙特卡洛工作相比，模型评估平均加速高达805倍，后验推断在精度-延迟权衡上具有帕累托优势，同时在均方根误差上与基准粒子滤波器保持竞争力。

## Abstract
Sensor-rich data-driven applications increasingly use Bayesian approaches to infer latent states of dynamic systems from noisy sensor measurements and physical models. Yet the computation of the likelihood remains an essential bottleneck for accurate posteriors and performant inference. This paper presents a Bayesian filtering technique that uses processor-native uncertainty tracking for both uncertainty propagation and inference. The technique implements deterministic hierarchical importance restructuring through a native operation, giving deterministic latency and bounded memory use for arbitrary models written as program code. Benchmarks across three nonlinear state-space systems compare the approach against particle filters and Monte-Carlo-based likelihood estimators. The technique enables deterministic approximate filtering with as high as 805$\times$ average speedup against direct Monte Carlo work at matched result quality for model evaluation, and Pareto-dominant accuracy-latency trade-offs for posterior inference while remaining competitive in RMSE with baseline particle filters.

- **整体含义**：本文提出一种基于**处理器原生不确定性跟踪**的新型贝叶斯滤波方法，旨在实现**确定性、低延迟、有界内存**的近似推理，同时保持与粒子滤波相当的估计精度，从而满足实时、资源受限系统的需求。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：利用专有硬件微架构（UxHw，Uncertainty-eXtended Hardware）原生支持概率密度函数的算术运算和贝叶斯推断。模型代码本身即作为似然函数，无需手动推导或近似。核心操作为 **BayesLaplace**，实现**确定性层次重要性重构**（Deterministic Hierarchical Importance Restructuring）。

## 3. 实验设计：数据集/场景、benchmark、对比方法

- **数据集/场景**：采用三个非线性状态空间系统，均来自实际应用：
    1. **随机波动率系统**（SV）：隐藏的对数方差过程，观测为带乘性噪声的指数变换。噪声：高斯或拉普拉斯。
    2. **Gordon–Salmond–Smith 系统**（GSS）：经典非线性基准，含强非线性转移和平方观测。噪声：高斯。
    3. **均值回复过程与指数异方差观测**（MR-Exp）：立方均值回复转移，观测为 Beer–Lambert 形式（指数衰减+乘性噪声+异方差加性噪声）。噪声：高斯、均匀、拉普拉斯。
- **Benchmark**：
    - **滤波器级评估**：对每个系统生成50条轨迹（trace），每个滤波器在每个轨迹上运行100次。计算 RMSE（点估计）、RMSE 标准差（稳定性）、负对数似然（NLL）、连续排序概率分数（CRPS，后验质量）。
    - **分解模型评估**：分别测试每个系统的转移模型和观测模型的 **确定性传播精度**与**速度**：
        - 对转移/观测模型，使用 UxHw（η∈{8,16,32}）与蒙特卡洛（MC）进行对比。
        - **等质量**（Iso-quality）：MC 迭代次数达到与 UxHw 相同 Wasserstein-1 距离，比较延迟，计算加速比。
        - **等时间**（Iso-time）：MC 在 UxHw 的运行时内最大迭代次数，比较 Wasserstein-1 距离，计算精度提升百分比。
    - **推断步骤评估**：对每个系统的似然模型，比较 UxHw BayesLaplace 与重要性采样（不同粒子数10~1000）的 **Wasserstein-1 距离**与延迟，绘制帕累托前沿。
- **对比方法**：**引导粒子滤波器**（Bootstrap Particle Filter, BPF）粒子数 ∈ {10,20,50,100,500,1000}。UxHw 配置 η ∈ {8,16,32,64}。所有方法均运行在同一硬件平台（UxHw-FPGA-17k 模块）。

## 6. 主要结论与发现

- **确定性近似滤波可行且高效**：UxHw BayesLaplace 滤波器在所有三个系统上实现了与粒子滤波竞争的 RMSE，同时具有 **确定性输出** 和 **可预测的低延迟**。
- **加速效果显著**：在等分质量（相同 Wasserstein-1 距离）下，UxHw 对转移/观测模型评估平均加速 **25倍到805倍**（最坏情况90分位可达1424倍）。在等时间下，UxHw 将 Wasserstein-1 距离降低 **77%–97%**。
- **帕累托主导的精度-延迟权衡**：在推断步骤（后验计算）的帕累托前沿中，UxHw 配置（尤其η=8,16）在整个延迟区间内精度优于同等或更高延迟的粒子滤波。仅在高延迟端（>100ms）粒子滤波也可能接近，但UxHw仍更具优势。
- **稳定性**：UxHw 的确定性使多次运行结果完全一致（数值精度内），而粒子滤波在低粒子数下变异大，可靠性降低。
- **依赖模型结构**：对于某些模型（如随机波动率观测、指数观测），UxHw 的加速比仅为数十倍而非数百倍，但依然优于蒙特卡洛。总体而言，η=8 对于资源受限系统最具吸引力，而更大 η 可换取更高尾部精度。

## 8. 不足与局限

- **硬件依赖**：目前仅能在专用 UxHw 硬件（FPGA）上运行，通用CPU/GPU上无法直接使用，限制了可迁移性。
- **对比不够全面**：仅对比了基本粒子滤波（BPF），未与更先进的变体（辅助粒子滤波、正则化粒子滤波）或解析方法（UKF、CKF）比较。也未在不同硬件平台上对标（如GPU加速的粒子滤波）。

- **未讨论多维状态**：论文仅处理一维状态（1D滤波器），虽然方法的原理可扩展至高维，但未提供高维实验验证（如目标跟踪中的高维问题），实际可扩展性尚不明确。
