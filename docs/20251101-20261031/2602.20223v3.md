## 摘要
近期，TabPFN作为表格数据的基础模型受到关注。然而，它难以整合图像和文本等异构模态，而这些模态在医疗和营销等领域十分常见，从而限制了其适用性。为解决这一问题，我们提出了多模态先验数据拟合网络（MMPFN），它将TabPFN扩展为以统一方式处理表格与非表格模态。MMPFN由各模态编码器、模态投影器和预训练基础模型组成。模态投影器作为关键桥梁，将非表格嵌入转换为与表格兼容的token以进行统一处理。为此，我们引入了多头门控MLP和交叉注意力池化器，从非表格输入中提取更丰富的上下文，同时缓解多模态学习中的注意力不平衡问题。在医疗和通用多模态数据集上的大量实验表明，MMPFN持续优于具有竞争力的最先进方法，并有效利用非表格模态与表格特征。这些结果凸显了将先验数据拟合网络扩展至多模态场景的前景，为异构数据学习提供了一个可扩展且有效的框架。源代码见 https://github.com/too-z/MultiModalPFN。

## Abstract
Recently, TabPFN has gained attention as a foundation model for tabular data. However, it struggles to integrate heterogeneous modalities such as images and text, which are common in domains like healthcare and marketing, thereby limiting its applicability. To address this, we present the Multi-Modal Prior-data Fitted Network (MMPFN), which extends TabPFN to handle tabular and non-tabular modalities in a unified manner. MMPFN comprises per-modality encoders, modality projectors, and pre-trained foundation models. The modality projectors serve as the critical bridge, transforming non-tabular embeddings into tabular-compatible tokens for unified processing. To this end, we introduce a multi-head gated MLP and a cross-attention pooler that extract richer context from non-tabular inputs while mitigates attention imbalance issue in multimodal learning. Extensive experiments on medical and general-purpose multimodal datasets demonstrate that MMPFN consistently outperforms competitive state-of-the-art methods and effectively exploits non-tabular modalities alongside tabular features. These results highlight the promise of extending prior-data fitted networks to the multimodal setting, offering a scalable and effective framework for heterogeneous data learning. The source code is available at https://github.com/too-z/MultiModalPFN.

## 1. 核心问题与研究动机

- **背景**：表格数据广泛存在于医疗、金融、营销等领域，传统上由梯度提升决策树（XGBoost、CatBoost、LightGBM）主导。近年深度表格模型（如 SAINT、SCARF）展现出更强表达能力，并逐渐向多模态场景延伸——例如诊断任务同时使用结构化检验结果与医学影像，营销任务结合销售记录与产品评论文本。
- **关键痛点**：TabPFN 作为表格基础模型，将表格监督学习视为摊销贝叶斯推断，在中小规模表格上单次前向即可获得强性能。但其预训练仅基于**合成表格数据**，缺乏向图像、文本等非结构化模态扩展的原则性方案。
- **现有方法的不足**：
  - 将 GBDT 扩展到异构数据类型收益有限；
  - 联合嵌入表格与图像/文本的深度模型在数据稀缺时性能受限、训练缓慢；
  - 已有工作（MMCL、TIP、STiL、TIME、Turbo 等）多聚焦视觉-语言任务，对结构化数据的系统处理有限，融合策略常为启发式，在低数据或模态不平衡下不可靠。
- **论文目标**：提出 MMPFN，首次将 TabPFN 扩展为统一处理表格 + 图像/文本的框架，并显式解决多模态学习中的两个失败模式。

## 2. 方法论

### 2.1 整体架构
MMPFN 由三部分组成：**各模态编码器 → 模态投影器 → TabPFN 主干**，最后由轻量解码头输出测试样本预测。

- **各模态编码器**：
  - 表格分支：与 TabPFN v2 编码器一致，微调时**冻结**；
  - 图像分支：DINOv2 ViT-B/14，图像尺寸调整为 14 的倍数，取 [CLS] token 作为全局表示；
  - 文本分支：ELECTRA 编码器（预实验中优于 DeBERTa 变体），截断至 512 token，取 [CLS] 嵌入。
- **训练策略**：冻结所有模态编码器，训练模态投影器、TabPFN 主干与解码器；沿用 TabPFN 的 in-context 协议——将训练集与测试集嵌入拼接为一张表输入主干，为测试样本产生预测并获取监督信号。

### 2.2 模态投影器（核心创新）
针对两个失败模式设计：

- **失败模式一：非表格嵌入过度压缩**（单一 [CLS] 向量信息量不足）
  - **多头门控 MLP（MGM）**：[CLS] 嵌入送入 N 个 MLP 头，将编码器输出维度投影到 d 维，产生 N 个候选模态 token；用 GLU（门控线性单元）调制各头贡献，促进头间专门化、保留多样信息。
- **失败模式二：token 数量差异导致的注意力不平衡**
  - **交叉注意力池化器（CAP）**：以 N 个 MGM token 为 key/value，引入 K 个可学习 query 向量做交叉注意力，得到每模态 K 个代表性 d 维嵌入，再经 MLP 精炼；这 K 个 token 与表格 token 沿特征维拼接，构成 TabPFN 的多模态输入表。

### 2.3 注意力不平衡的理论分析
- 设查询 q 分别对 N_I 个非表格 token 与 N_T 个表格 token 计算缩放点积注意力，未归一化权重为 w，定义每 token 期望 c_I、c_T，则非表格集合获得的总注意力权重期望近似为：

  **E[a_I] ≈ N_I·c_I / (N_I·c_I + N_T·c_T)**

- 结论：当每 token 质量相当（c_I ≈ c_T）时，token 数量多的一方会占据更大注意力预算，抑制另一方信号。这从理论上解释了为何需要 CAP 将非表格 token 压缩为紧凑集合。

## 6. 主要结论与发现

1. **性能领先**：MMPFN 在表格-图像任务上平均排名 1.50（最优），在表格-文本任务上平均排名 2.25（最优），在 PU20、Calc、Petfinder 图像任务及 Airbnb 上取得第一。
2. **有效利用非表格模态**：相比仅用表格的微调 TabPFN，加入图像/文本后性能一致提升；在 PetFinder 上随模态递增（T→T+t→T+I→T+I+t）准确率单调上升（约 39%→40%→41%），且每种组合均优于 AutoGluon。
3. **注意力不平衡得到实证支持**：非表格 token 数增加时，其注意力质量单调上升、表格 token 注意力下降；性能在两类 token 数量接近时最佳；MGM+CAP 通过"多 token 提取 + 压缩到 24 个 CAP token"稳定优于纯 MGM。
4. **MGM 与 CAP 各自有效**：MGM 在所有数据集上优于 Linear/MLP/MoE；CAP 在所有数据集上优于 FiLM；GLU 相比 GELU 既提升准确率又提高输出向量正交性。
5. **低数据鲁棒性**：仅用 10% 数据时，MMPFN 平均准确率 64.21，仍高于 TIP 的 58.97；在 Mass 上甚至因欠采样而性能提升（+0.75%）。
6. **跨模态交互确实被建模**：余弦相似度显示除模态内高相似块外，存在多个强对齐的表格-图像/文本特征对。
7. **额外发现**：MMPFN 在纯非表格输入下也接近 DINOv2+MLP 基线（69.30% vs 69.89%），说明 TabPFN 并非只能处理原生表格输入；额外的 MMD 分布对齐正则反而有害，说明 MGM/CAP 已实现足够对齐。

## 7. 优点

- **问题定位清晰**：首次系统性地将 PFN 范式扩展到多模态表格学习，填补 TabPFN 无法处理异构模态的空白。
- **方法论有理论支撑**：对注意力不平衡给出简洁的期望权重公式推导，并用多组实验（token 比例扫描、注意力质量测量、token 数与表示质量解耦）交叉验证，机理与现象闭环较好。
- **组件设计有针对性**：MGM 解决"过度压缩"、CAP 解决"token 失衡"，二者分工明确；GLU 门控还带来表示多样性（正交性提升）的附加证据。
- **工程友好**：冻结编码器、仅微调投影器与主干、100 步微调，训练成本低；模块化设计便于替换更强编码器（DINOv3 替换带来约 +0.74% 提升）。
- **实验较全面且诚实**：覆盖 9 个数据集、多类基线、多组消融；补充材料主动报告负结果（MMD 正则无效、patch-token 更差、低数据相对跌幅更大），可信度较高。
- **实用价值明确**：在表格模型性能趋于饱和的背景下，指出"增加互补模态"是继续提升的可行路径。
