## 摘要
我们开发了用于随机神经网络模型中不确定性传播的解析方法和基于粒子的方法，其中输入和网络参数均允许是随机的。基于Leaky ReLU激活函数的分段线性结构，我们推导了神经网络输出关于其输入和参数扰动的局部近似。该近似对于保持网络激活模式的扰动是精确的，并且使我们能够计算网络输出的概率密度函数和特征函数的解析表达式，以及其均值和协方差的闭式近似。我们将这一不确定性传播框架扩展到一步演化映射由随机神经网络表示的自主动力系统。该映射的重复应用定义了自回归模型，为此我们推导了递归方程，以随时间传播状态和网络参数中的不确定性。这些方程明确考虑了在网络的连续迭代下产生的状态-参数互协方差。在Lorenz-63系统和Kuramoto-Sivashinsky方程上的数值实验证明了在可预测性范围内准确的不确定性传播，以及所提出框架对高维动力系统的适用性。

## Abstract
We develop analytical and particle-based methods for uncertainty propagation in random neural network models, where both the inputs and network parameters are allowed to be random. Building on the piecewise-linear structure of the Leaky ReLU activation function, we derive a local approximation of the neural network output with respect to perturbations in both its inputs and parameters. This approximation is exact for perturbations that preserve the network activation pattern, and it allows us to compute analytical expressions for the probability density function and characteristic function of the network output, together with closed-form approximations for its mean and covariance. We extend this uncertainty propagation framework to autonomous dynamical systems whose one-step evolution map is represented by a random neural network. Repeated application of this map defines an autoregressive model, for which we derive recursive equations to propagate uncertainty in both the state and network parameters over time. These equations explicitly account for the state-parameter cross-covariance that develops under successive iterations of the network. Numerical experiments on the Lorenz-63 system and the Kuramoto-Sivashinsky equation demonstrate accurate uncertainty propagation through the predictability horizon and the applicability of the proposed framework to high-dimensional dynamical systems.

- **核心问题**：当神经网络的**输入**和**网络参数**均为随机时，如何高效、准确地传播不确定性？特别是在自回归动态系统中，网络被反复迭代应用，输出分布本身成为下一步的输入分布，不确定性随时间的累积与演化成为一个关键挑战。
- **核心洞察**：Leaky ReLU激活函数具有分段线性结构，因此在每个线性区域内，网络输出对输入和参数的一阶泰勒展开是**精确**的。这为解析地刻画不确定性传播提供了独特优势。
- **整体意义**：该工作填补了随机神经网络（输入和参数同时随机）在自回归动力学预测场景下不确定性传播方法的空白，为高维混沌动力系统的可信预测提供了新工具。

## 2. 论文提出的方法论

### 2.1 核心思想
- 将神经网络输出视为输入 $x$ 和参数 $\theta$ 的联合函数，对其进行一阶泰勒线性化：
  $$F_{\bar{\theta}+\Delta\theta}(\bar{x}+\Delta x) \approx F_{\bar{\theta}}(\bar{x}) + J \begin{bmatrix}\Delta x \\ \Delta\theta\end{bmatrix}$$
  其中 $J = [J_x \;\; J_\theta]$ 是组合雅可比矩阵（输入雅可比与参数雅可比拼接）。
- 由于Leaky ReLU的分段线性特性，只要扰动不改变网络的激活模式，该近似是**精确的**。
- 这一线性化框架被推广到自回归设置：网络作为时间步进映射 $x_{t+1}=F_\theta(x_t)$ 被反复应用。

### 2.2 概率密度函数与特征函数的解析推导
- 利用Dirac delta的Fourier积分表示，推导出网络输出的PDF一般表达式：
$$p(y) = \frac{1}{(2\pi)^M}\int_{\mathbb{R}^M} e^{ia^T[y-F_{\bar{\theta}}(\bar{x})]} \phi_{\Delta x,\Delta\theta}(-J^T a)\, da$$
- 输出特征函数可简洁表示为：
$$\phi_y(\omega) \approx e^{i\omega^T F_{\bar{\theta}}(\bar{x})} \phi_{\Delta x,\Delta\theta}(J^T \omega)$$
- 该式表明：在线性化近似下，输出PDF完全由输入与参数扰动的**联合特征函数**决定。

### 2.3 三种统计模型下的特化
- **高斯扰动**：输出精确服从 $y \sim \mathcal{N}(F_{\bar{\theta}}(\bar{x}), J\Sigma_\Delta J^J)$。
- **独立扰动**：联合特征函数因子化为各分量特征函数之积。
- **独立均匀扰动**：特征函数为sinc函数的乘积。

### 2.4 自回归设置下的矩传播
- **均值更新**：$E[x_{t+1}] \approx \bar{x}_{t+1} = F_{\bar{\theta}}(\bar{x}_t)$
- **协方差更新**：
$$\Sigma_{t+1} \approx J_{x_t}\Sigma_t J_{x_t}^T + J_{\theta_t}\Sigma_{\Delta\theta} J_{\theta_t}^T + J_{x_t}\Sigma_{\Delta x_t,\Delta\theta} J_{\theta_t}^T + J_{\theta_t}\Sigma_{\Delta\theta,\Delta x_t} J_{x_t}^T$$
- **状态-参数交叉协方差递归更新**：
$$\Sigma_{\Delta x_{t+1},\Delta\theta} = J_{x_t}\Sigma_{\Delta x_t,\Delta\theta} + J_{\theta_t}\Sigma_{\Delta\theta}$$
- 关键发现：即使初始状态与参数扰动的独立性成立，经过一次自回归传播后，状态与参数就变得统计相关，必须显式传播交叉协方差项。

### 2.5 传播算法
- **Algorithm 1（单高斯传播）**：仅传播均值、协方差和交叉协方差，用单个高斯近似状态分布。
- **Algorithm 2（蒙特卡洛基线）**：直接从初始联合分布采样，通过完整非线性网络传播。
- **Algorithm 3（重采样矩传播，RMP）**：粒子方法，交替进行**解析矩传播**与**周期性重采样**：
  - 每个粒子携带局部高斯分布（均值+协方差）；
  - 重采样步将局部高斯转换为新的粒子云，并重置局部协方差为零；
  - 提供两种重采样策略：每个高斯取一个样本（保持粒子数），或从高斯混合模型中采样（L>1后均匀子采样回S个粒子）。

## 3. 实验设计

- 两个系统均使用MLP（多层感知机）作为一步演化映射的代理模型，激活函数为Leaky ReLU。

## 6. 论文的主要结论与发现

1. **线性化框架的有效性**：基于Leaky ReLU分段线性结构的联合输入-参数线性化（4），为不确定性传播提供了精确的局部描述，并能导出输出PDF、特征函数的解析表达式及均值协方差的闭式近似。
