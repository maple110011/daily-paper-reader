## 摘要
漂移扩散模型（DDM）是认知决策研究的基石。尽管存在众多估计方法，研究人员仍在寻求在不同研究设计下既快速又灵活的推断方法。摊销贝叶斯推断（ABI）可以为像DDM这样的复杂随机模型提供近乎即时的推断，但为一个研究设计训练的神经网络无法泛化到其他设计。在本文中，我们提出了一种分而治之框架来解决这一局限。核心思想是，DDM的独立性假设允许将完整数据集分解为成对的分片（shards），每个分片共享一个可由单个神经网络学习的公共结构。对每个分片分别进行推断，并通过共识MCMC（consensus MCMC）合并所得后验，以近似完整的后验。使用模拟数据集，我们评估了该方法的准确性和不确定性。我们的结果表明，所提出的分而治之方法在实现与MCMC相当的准确性和不确定性的同时，将计算成本降低了几个数量级。这项工作不仅推进了DDM估计，还展示了一种通用策略，用于提高ABI方法在各种应用中的可扩展性和泛化性。

## Abstract
The drift diffusion model (DDM) is a cornerstone of cognitive decision-making research. Although numerous estimation methods exist, researchers continue to seek inference approaches that are both fast and flexible across diverse study designs. Amortized Bayesian inference (ABI) can provide nearly instantaneous inference for complex stochastic models like the DDM, but neural networks trained for one study design cannot generalize to others. In this paper, we propose a divide-and-conquer framework that address this limitation. The core idea is that the DDM's independence assumption allows the full dataset to be decomposed into pairwise shards, each sharing a common structure that a single neural network can learn. Inference is performed on each shard separately and the resulting posteriors are combined via consensus MCMC to approximate the full posterior. Using simulated datasets, we evaluate the accuracy and uncertainty of this method. Our results show that the proposed divide-and-conquer approach achieves accuracy and uncertainty comparable to MCMC while reducing computational cost by several orders of magnitude. This work not only advances DDM estimation but also demonstrates a general strategy for improving the scalability and generalizability of ABI methods across diverse applications.

### 二、提出的方法论：分而治之框架

该框架的基本流程包含以下关键步骤：

**核心思想**：利用 DDM 的试次独立性与条件独立性假设，将完整数据集（如包含 4 个条件的数据）分解为多个互不重叠的成对分片（shards），每个分片包含两个条件。由于分解是互斥且穷尽的，完整的似然函数可以精确因式分解为各分片似然的乘积，不损失任何信息。

- **数据分解策略**：以 3 条件设计为例，将每个条件的试次均分为两半，得到 6 个子集，组合成 3 个成对分片：S1 = (条件1, 条件2)、S2 = (条件1, 条件3)、S3 = (条件2, 条件3)。每个分片共享相同的模型结构：两个条件、两个漂移率、一组公用参数（a, z, Ter）。由此，一个仅需在成对数据上训练的 NPE 可以处理任意条件数量的实验设计。
- **成对后验估计**：对每个分片分别应用成对 NPE（或 MCMC）获得成对后验 p(θ|Sq)。
- **共识 MCMC 合并**：通过共识 MCMC（consensus MCMC）将 Q 个分片的后验合并为共识后验。理论依据是 Bernstein-von Mises 定理，即大样本下各分片后验近似服从高斯分布，高斯密度的乘积仍为高斯，其均值是各分片均值的精度加权平均。具体公式为：

  θl = (Σq Wq⁻¹)⁻¹ Σq Wq⁻¹ θql

  其中 θql 为第 q 个分片的第 l 个后验样本，Wq 为该分片的边际后验协方差矩阵（实际中近似为对角阵）。

- **重要性采样校准**：由于每个分片都使用了完整先验 p(θ)，先验被重复使用了 Q 次，导致共识后验中的有效先验变成 p(θ)Q。论文通过重要性采样对共识后验样本重新加权，权重 w(θ) ∝ p(θ)^(1−Q)，以消除先验重复使用的扭曲，得到校准后的共识后验（calibrated consensus posterior）。
- **概念区分**：论文明确区分了四类后验——（a）成对后验（条件于单个分片）、（b）共识后验（经共识 MCMC 平均）、（c）校准共识后验（经重要性采样校正）、（d）完整后验（条件于完整数据集，作为基准）。

### 八、不足与局限

- **依赖 i.i.d. 假设**：框架要求试次和条件间相互独立。一旦存在序列依赖（如漂移率受前一试次结果影响），成对分解将产生偏差。这一前提限制了框架在连续学习、自适应实验等场景的应用。
- **小样本条件性能下降**：在条件内试次数极少的真实数据中，成对后验偏离高斯性，导致共识 MCMC 合并后准确性下降，漂移率尾部估计偏向极端，后验 SD 大于全模型。论文未提出针对小样本条件的改进方案。
- **参数估计不均匀**：边界分离参数 a 在成对估计中 RMSE 和 SD 均高于全模型估计，表明该框架对某些参数（尤其受条件间共享信息影响较大的参数）的恢复不如其他参数稳健。
- **训练-测试分布不一致**：训练先验较宽（v 可从 -15 到 15，a 可从 0 到 6），而测试参数分布较窄。若测试参数落在先验稀疏区域，估计可能出现偏差。
- **评估基准的限定性**：模拟数据均基于同一种 DDM 生成过程，未测试模型误设情形下（如刺激编码时间分布、试次间参数变异等）框架的稳健性。
- **不可否认的折衷**：在极为庞大且高度不平衡的真实设计中（如 rr98），分治估计的绝对数值与全模型存在可见差异（如边界分离 aaccuracy 差 0.3–0.5），说明分治方法的适用性受数据条件质量约束。
