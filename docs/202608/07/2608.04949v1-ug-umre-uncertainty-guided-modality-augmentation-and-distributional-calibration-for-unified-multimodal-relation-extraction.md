## 摘要
统一多模态关系抽取（UMRE）旨在识别文本实体与视觉对象之间的模态内和跨模态关系。然而，现有的UMRE研究仍面临两个关键问题：忽略固有的任意不确定性导致噪声传播，以及不同模态分布之间的深层异质性阻碍对齐。为解决这些问题，我们提出了不确定性引导的UMRE网络（UG-UMRE）。具体而言，我们设计了一个不确定性驱动的单模态增强（UDUA）模块，该模块基于变分信息瓶颈将特征建模为高斯分布。通过引入不确定性感知的自监督对比学习机制，UDUA在保持语义一致性的同时有效过滤噪声。此外，我们引入了联合任意不确定性对齐（JAUA）模块作为全局语义预校准机制。JAUA利用概率分布一致性构建共享潜在空间，通过同步跨模态统计属性消除分布差距，从而为细粒度交互奠定坚实基础。在三个基准数据集（UMRE、MORE和MNRE）上的实验表明，UG-UMRE达到了最先进的性能。进一步分析验证了所提出的UDUA和JAUA模块的可插拔性和有效性。

## Abstract
Unified Multimodal Relation Extraction (UMRE) aims to identify intra-modal and cross-modal relations between textual entities and visual objects. However, existing UMRE studies still encounter two critical issues: ignoring inherent aleatoric uncertainty causes noise propagation, and deep-seated heterogeneity between distinct modal distributions hinders alignment. To address these issues, we propose the Uncertainty-Guided UMRE Network (UG-UMRE). Specifically, we design an Uncertainty-Driven Unimodal Augmentation (UDUA) module, which models features as Gaussian distributions based on the Variational Information Bottleneck. By incorporating an uncertainty-aware self-supervised contrastive learning mechanism, UDUA effectively filters out noise while maintaining semantic consistency. Furthermore, we introduce the Joint Aleatoric Uncertainty Alignment (JAUA) module as a global semantic pre-calibration mechanism. JAUA leverages probabilistic distribution consistency to construct a shared latent space, eliminating the distributional gap by synchronizing cross-modal statistical properties, thereby laying a robust foundation for fine-grained interaction. Experiments on three benchmark datasets (UMRE, MORE, and MNRE) demonstrate that UG-UMRE achieves state-of-the-art performance. Further analysis validates the pluggable and effective performance of the proposed UDUA and JAUA modules.

## 1. 核心问题与研究动机

统一多模态关系抽取（UMRE）是一个新兴任务，目标是在统一框架下同时抽取文本实体之间、视觉对象之间以及文本实体与视觉对象之间的模态内和跨模态关系。它比早期的 MNRE（仅以图像为辅助线索抽取文本内实体关系）和 MORE（引入视觉对象到关系三元组）更贴合真实场景，但任务复杂度也显著提升。论文指出当前 UMRE 方法存在两大关键挑战：

- **模态噪声**：不同模态的输入数据具有固有的任意不确定性（aleatoric uncertainty），例如图像存在背景杂乱、文本存在俚语或歧义。忽略这种内在随机性会导致噪声传播，模型容易过拟合虚假关联。
- **模态鸿沟**：文本和视觉特征来自异构编码器（如 BERT 与 ViT），二者处于不同特征空间和分布中，直接融合容易导致语义错位，阻碍细粒度跨模态交互。

现有方法（如 REMOTE）虽然通过结构化聚合（如多级最优传输、混合专家）取得不错效果，但缺乏融合前的去噪与分布校准，因而性能受限。论文的核心主张是：在进行跨模态融合之前，应遵循“先降噪、再校准、后融合”的范式。

## 2. 方法论

### 2.1 总体框架

UG-UMRE 由四个阶段组成：

1. **特征获取**：使用 BERT、ViT、Depth-Anything 获取文本与视觉特征，并结合 Qwen2.5-VL 生成的描述，再通过多级最优传输（MOT）聚合层级表示。
2. **不确定性驱动的单模态增强（UDUA）**：对单模态特征进行概率建模与去噪。
3. **联合任意不确定性对齐（JAUA）**：在分布层面对文本和视觉特征进行全局校准。
4. **层次化跨模态交互与混合专家（MMoE）**：在校准后的特征空间中进行细粒度交互和关系预测。

### 2.2 UDUA 模块

- **VIB 建模**：将整体池化后的特征映射为高斯分布 \(\mathcal{N}(\mu, \sigma^2 I)\)，其中 \(\mu\) 表示稳定核心语义，\(\sigma^2\) 量化任意不确定性。
- **信息瓶颈目标**：使用变分信息瓶颈（VIB）约束，通过 KL 散度压缩无关噪声，并通过交叉熵保留任务相关信息。
- **不确定性感知对比学习**：利用重参数化技巧，从当前样本分布中采样作为正样本，同一批次其他样本分布中采样作为负样本，使用 InfoNCE 损失迫使模型在语义空间聚合稳定中心，实现分布感知去噪。

### 2.3 JAUA 模块

- 计算文本分布与视觉分布之间的双向 KL 散度（对称 KL），同步均值（语义中心）和方差（不确定性尺度）。
- 该损失作为全局预校准，只在整体潜在变量上作用，保留原始序列中的局部模态细节，不覆盖具体局部线索。
- 通过最小化该损失，构造共享潜在空间，消除跨模态分布差距。

### 2.4 交互与预测

- 采用层次化跨模态注意力（HCMI），利用高层源特征作为 Query，对互补模态的每一层特征进行注意力计算，生成视觉引导的文本特征和文本引导的视觉特征。
- 使用 MMoE 动态融合最优单模态表示和跨模态交互表示。
- 对文本实体使用 [CLS] 对应特征，对视觉对象则结合对象描述文本特征与视觉特征，最终通过 MLP 分类器预测关系。

### 2.5 联合训练

总损失为：
\[
\mathcal{L} = \mathcal{L}_{umre} + \lambda_1 \mathcal{L}_{IB} + \lambda_2 \mathcal{L}_{SCL} + \lambda_3 \mathcal{L}_{JAUA}

其中各项分别为主任务交叉熵、信息瓶颈损失、自监督对比损失和分布对齐损失。

## 3. 实验设计

### 3.1 数据集与评测指标

- **数据集**：三个公开基准——UMRE（12,737 图像/句、20,978 视觉对象、55,021 三元组、28 种关系）、MORE（3,559 图像/句、13,520 视觉对象、20,264 三元组、21 种关系）、MNRE（9,201 图像/句、15,485 三元组、23 种关系）。
- **指标**：精确率（P）、召回率（R）、F1 值。

### 3.2 对比方法

- **MRE 模型**：MEGA、MKGFormer、IFAformer、MRE-ISE、MOREformer、MMIB、HVFormer、CGI-MRE、FocalMRE、REMOTE。
- **多模态大模型（MLLMs）**：Qwen2-VL-7B、Qwen2.5-VL-7B、Llama-3.2-11B-Vision。
- **可插拔验证**：将 UG-UMRE 分别集成到 REMOTE（增强输入）和 FocalMRE（原始输入）中，以验证模块在不同输入配置下的通用性。

### 3.3 主要结果

- 集成到 REMOTE 后，UG-UMRE 在三个数据集上 F1 分别提升 2.34%、3.95%、2.25%，达到 69.98%、66.76%、89.59%，均为新的 SOTA。
- 在 FocalMRE 基础上集成也获得一致提升（如 UMRE F1 从 63.57% 到 65.49%）。
- MLLMs 性能明显低于专用模型，说明大模型在细粒度关系抽取上仍不占优势。

## 6. 主要结论与发现

- UG-UMRE 在三个基准数据集上达到 SOTA，显著优于当前最强的 REMOTE。
- **UDUA 单独带来的增益略大于 JAUA**，说明高质量去噪是有效跨模态对齐的前提。
- **全局预校准必不可少**：仅依赖结构聚合（如 MOT）无法突破模态鸿沟造成的性能瓶颈。
- **可插拔性强**：不改变骨干网络的输入输出接口，即可在不同方法上稳定提升性能，可作为通用“安全阀”和“校准器”。
- **抗噪能力突出**：在 100% 极端噪声下，REMOTE+UDUA 比 REMOTE 高出 17.32% F1，验证了不确定性量化在抑制噪声传播中的有效性。
- **长尾关系改善明显**：如 /per/per/opponent 关系 F1 提升 19.36%，/per/misc/race 从 0 提升到 66.67%。

## 7. 优点

- **问题定位精准**：明确指出现有 UMRE 方法在融合前缺乏去噪与分布校准的缺陷，所提范式“去噪—校准—融合”逻辑清晰。
- **概率建模自然**：用 VIB 将特征建模为高斯分布，用方差显式表征任意不确定性，避免了确定性点嵌入的语义模糊。
- **模块可插拔**：UDUA 和 JAUA 作为轻量模块可集成到其他模型中，不改变原有接口，实用性强。
- **损失设计合理**：自监督对比学习与信息瓶颈互补，前者增强判别性，后者保持任务相关性；JAUA 双向 KL 同时对齐均值和方差，实现全局预校准。
- **实验充分且公平**：区分增强输入与原始输入，并在多种基线上验证；噪声鲁棒性和长尾分析展示了方法的稳健性和实际价值。
- **计算开销小**：相对 REMOTE 仅增加 0.49% 参数和 3.7G FLOPs，推理时间增加约 4ms/样本，效率实用。

## 8. 不足与局限

- **算力细节缺失**：未报告训练时长、具体 GPU 利用率和总计算成本，不利于复现时的资源评估。
- **依赖人工设置的超参数**：损失权重 \(\lambda_1, \lambda_2, \lambda_3\)、温度 \(\tau\) 和拉格朗日乘子 \(\beta\) 均为固定值，论文也承认固定损失权重对稀疏关系可能不够可靠。
- **不确定性建模粒度较粗**：UDUA 仅在整体池化后的向量上建模高斯分布，捕获的是全局不确定性，未对局部 token/object 级噪声进行显式建模，可能限制对细粒度噪声的过滤能力。
- **长尾与极端少见关系依然脆弱**：对于测试集中样本数量极少的类别（如 count ≤ 5），模型仍无法预测，改进有限。
- **对比 MLLMs 的公平性问题**：MLLMs 使用零样本/少样本指令方式评测，而专用模型经过数据集训练，二者性能差距大，虽然可以说明大模型不擅长该任务，但对比条件不完全对等。
- **可插拔性仅验证了两种模型**：虽然两种模型具有代表性，但尚未在更多异构架构上验证普适性。
- **应用场景有限**：实验数据全部来自社交媒体场景，泛化到其他领域（如生物医学、法律文本）未经测试。
