## 摘要
离线强化学习利用静态数据集学习决策策略，无需实时环境交互。虽然最近的序列建模方法依赖连续扩散模型进行轨迹合成，但将这些方法应用于离散规划任务需要分类公式而非标准高斯构造。我们提出BFN-RL，一个基于贝叶斯流网络的离线强化学习统一生成建模框架。通过迭代演化分布参数而非噪声数据实例，BFN-RL在单一概率公式中原生建模离散和连续轨迹空间。分类规划器生成未来状态序列，学习到的逆动力学模型将连续生成的状态转换为动作。在离散规划和连续控制中的评估表明，BFN-RL能够在分类和连续状态空间中生成有效轨迹。我们的结果确立了贝叶斯流网络作为跨数据模态离线轨迹规划的多功能生成基础。

## Abstract
Offline reinforcement learning (RL) leverages static datasets to learn decision policies without real-time environment interaction. While recent sequence-modeling approaches rely on continuous diffusion models for trajectory synthesis, applying these methods to discrete planning tasks requires a categorical formulation rather than the standard Gaussian construction. We present BFN-RL, a unified generative modeling framework for offline RL based on Bayesian Flow Networks (BFNs). By iteratively evolving distribution parameters rather than noisy data instances, BFN-RL natively models both discrete and continuous trajectory spaces within a single probabilistic formulation. The categorical planner generates future state sequences, and a learned inverse-dynamics model converts consecutive generated states into actions. Evaluations in discrete planning and continuous control show that BFN-RL can generate effective trajectories across both categorical and continuous state spaces. Our results establish BFNs as a versatile generative foundation for offline trajectory planning across data modalities.

## 1. 论文的核心问题与整体含义

- **研究背景**：离线强化学习（Offline RL）利用静态数据集训练策略，避免在线探索的风险，适合自动驾驶、医疗决策等高风险场景。近年来，将离线 RL 视为条件序列建模问题（如 Diffuser、Decision Diffuser）已成为主流，但这些方法几乎都依赖高斯连续扩散模型（DDPM）。
- **核心问题**：连续高斯扩散模型天然不适合离散状态/动作空间；离散规划任务需要分类（categorical）生成公式。现有离散扩散模型在高质量离散数据生成上仍不理想，且缺少统一处理离散与连续轨迹的生成框架。
- **论文目标**：提出 **BFN-RL**，基于**贝叶斯流网络（Bayesian Flow Networks, BFNs）**，通过迭代演化分布参数（而非噪声数据实例），在同一个概率公式内原生支持离散、连续以及离散化变量，从而为离线轨迹规划提供跨模态的统一生成基础。

## 2. 论文提出的方法论

- **核心思想**：与扩散模型“加噪—去噪”不同，BFN 从先验分布出发，通过贝叶斯更新迭代演化输入分布的参数 `θ_i`，逐步逼近数据分布。训练时，用带噪样本更新参数，神经网络将参数转换为输出分布，再与发送者分布计算 KL 散度作为损失。
- **关键组件（离散情形）**：
  - **输入分布**：因子化的分类分布，初始为均匀分布。
  - **输出分布**：神经网络 `Ψ_ω(θ_i, i)` 输出的分类分布。
  - **发送者分布**：以 one-hot 编码和精度参数 `α` 定义的高斯形式 `pS(y|x;α) = N(y | α(Aex−1), αA I)`。
  - **接收者分布**：输出分布与发送者分布的卷积。
  - **贝叶斯更新**：`h(θ_i, y_i) = (e^{y_i} ⊙ θ_i) / Σ_a e^{y_i,a} (θ_i)_a`。
- **训练损失**：使用连续时间 BFN 损失，并额外加入权重为 0.5 的干净数据交叉熵损失（`L_CE`）。
- **BFN-RL 方法**：
  - 只建模**状态序列**，不直接建模动作，类似于 Decision Diffuser。
  - 使用**逆动力学模型**：由连续的两个状态预测动作（MLP，两层 256 单元）。
  - **回报条件**：采用 classifier-free 方式，将回报作为网络输入条件，从而在采样时偏向高回报轨迹。
  - **当前状态条件**：采用类似扩散模型 inpainting 的思路，在采样过程中将已知当前状态的分布参数固定为对应值（离散版见 Algorithm 2，连续版见 Appendix Algorithm 3）。
  - 连续控制中使用一阶 BFN 求解器（Xue et al. 2024），10 步采样，指导权重 1.2，温度 0.5。
