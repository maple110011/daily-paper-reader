## 摘要
我们研究了中心化 Erdős--Rényi 分布（Lunagòmez 等，2021）的分布性质，并提出了一种用于多重网络数据的半共轭贝叶斯方法。在模拟中，Gibbs 采样和经验贝叶斯都能准确恢复网络汇总统计量，其中后者能随网络规模高效扩展。作为本短文的配套，我们提供了 R 包 BayesCER，实现了所提出的方法。

## Abstract
We investigate distributional properties of the centered Erdős--Rényi distribution (Lunagòmez et al., 2021) and propose a semi-conjugate Bayesian approach to multiple network data. In simulations, both Gibbs sampling and empirical Bayes accurately recover network summaries, with the latter scaling efficiently with network size. As a companion to this note, we provide the R package BayesCER, which implements the proposed methodology.
