## 摘要
心脏模型个体化需要推断无法在体内直接测量的力学参数。超快超声剪切波弹性成像（SWE）能够无创追踪整个心动周期内的心肌硬度动态变化，为个体化提供目标。然而，将这些观测映射到受试者特异性模型参数仍然是不适定的，因为多个参数集可以复现相同的硬度动态。我们将SWE信息引导的个体化表述为使用基于仿真的推断（SBI）的统计推断问题。使用受试者适配的0D心血管模型和神经后验估计，我们估计以SWE导出的曲线特征和受试者特异性背景为条件的、针对主动硬度尺度k0、收缩速率kATP和松弛速率kSR的模型条件后验分布。在六名健康志愿者中，四名通过了客观的先验支撑诊断，并被保留用于定量后验分析。相对于观测到的SWE目标，曲线级RMSE从先验预测中位数的12.61 ± 5.55 kPa降至后验预测中位数的1.14 ± 0.38 kPa，降低了89.7 ± 4.2%。后验分析揭示了参数特异性不确定性、k0-kATP补偿、kSR约束较弱，以及先验预测诊断对于评估每名受试者是否被表征在建模的SWE特征空间内的重要性。这些结果支持将SBI用于不确定性感知的基于SWE的个体化，同时将先验支撑和前向模型充分性确定为关键诊断。

## Abstract
Cardiac model personalisation requires inferring mechanical parameters that are not directly measurable in vivo. Ultrafast ultrasound shear wave elastography (SWE) enables non-invasive tracking of myocardial stiffness dynamics over the cardiac cycle, providing a target for personalisation. However, mapping these observations to subject specific model parameters remains ill-posed, as multiple parameter sets can reproduce the same stiffness dynamics. We formulate SWE-informed personalisation as a statistical inference problem using simulation-based inference (SBI). Using a subject-adapted 0D cardiovascular model and neural posterior estimation, we estimate model-conditional posterior distributions over active stiffness scale k0, contraction rate kATP, and relaxation rate kSR, conditioned on SWE-derived curve features and subject specific context. Among six healthy volunteers, four passed objective prior-support diagnostics and were retained for quantitative posterior analysis. Curve-level RMSE against the observed SWE target decreased from 12.61 $\pm$ 5.55 kPa for the prior predictive median to 1.14 $\pm$ 0.38 kPa for the posterior predictive median, an 89.7 $\pm$ 4.2% reduction. Posterior analysis revealed parameter-specific uncertainty, k0-kATP compensation, weaker constraint of kSR, and the importance of prior-predictive diagnostics for assessing whether each subject is represented within the modelled SWE feature space. These results support SBI for uncertainty aware SWE-based personalisation, while identifying prior support and forward-model adequacy as key diagnostics.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题起点**：心脏电机械模型的个体化（personalisation）需要推断体内无法直接测量的力学参数（如主动收缩能力、松弛速率），通常只能从影像运动、形变、心室容积或压力点等间接测量中反推。
- **不适定性（ill-posedness）**：临床数据稀疏、参数间强耦合，同一组观测可能由多组不同参数复现，导致参数估计不确定、相关或仅部分可辨识（practically identifiable）。因此，仅给出"单一最优拟合参数向量"不足以支撑可靠结论，必须回答"哪些属性真正被数据约束"。
- **SWE 的机会与挑战**：超快剪切波弹性成像（SWE）可无创追踪整个心动周期的心肌硬度动态，提供比射血分数、压力-容积环更直接的组织级观测；但 SWE 测得的表观硬度同时混合了被动组织响应、主动力生成与测量变异，单靠拟合硬度曲线无法唯一辨识主动力学参数。
- **方法学缺口**：MCMC 需要反复计算似然；近似贝叶斯计算（ABC）依赖人工距离函数与接受阈值。基于仿真的推断（SBI）直接从模拟数据学习后验近似，适合似然不可解模型，并可摊销（amortise）推断、刻画非高斯不确定性与参数依赖。但 SBI 在心血管建模中此前主要用于血流动力学生物标志估计，尚未用于 SWE 引导的心肌主动力学个体化。
- **论文定位**：提出"背景条件化（context-conditioned）SBI"框架，把 SWE 引导的主动力学个体化重构为概率推断问题，输出参数后验分布而非点估计，并显式评估先验支撑与前向模型充分性。
- **主要贡献（作者自述）**：
  - (i) SWE 主动参数估计的概率化表述；
  - (ii) 特征化观测模型，显式容纳刚度目标中的不确定性；

## 2. 方法论

### 2.1 观测目标：SWE 硬度曲线

- 采集：胸骨旁长轴切面，目标为基底段前室间隔；Verasonics Vantage 系统 + GE 6S-D 探头；声辐射力推挤 4 MHz、300 μs、f-number = 1；ECG 门控，心动周期内 20 个相位。
- 处理：对分割的心肌中层区域内剪切波速度估计做空间平均；由平均剪切波速 c_s 换算表观杨氏模量 **E = 3ρc_s²**（ρ = 1000 kg/m³）。
- 输出：对每个受试者 d 得到周期归一化的硬度曲线 E_SWE,d(s)，s ∈ [0,1]，直接作为推断观测 **E_obs,d(s) = E_SWE,d(s)**。

### 2.2 前向模型：背景适配的 0D 心血管模型

- 结构：降阶 0D 心血管仿真器；左心室建模为厚壁球形腔，耦合闭环体循环 RCR 与肺循环 RC Windkessel 循环；各向同性纤维假设下将心室几何约化为球对称，同时保留组织本构描述。
- 受试者背景 c_d：LVESV、LVEDV、IVSd、心率 HR、年龄、性别、体表面积 BSA。
- 由 HR、IVSd、LVEDV 定义个体化参数：心动周期 T_d = 60/HR_d；参考壁厚 d_0,d = 10⁻²·IVSd_d；参考半径 R_0,d = (3·10⁻⁶·LVEDV_d / 4π)^(1/3)（HR、IVSd、LVEDV 单位分别为 bpm、cm、mL）。LVESV、年龄、性别、BSA 仅作为条件变量。
- **待推断的主动参数向量 θ = (k₀, k_ATP, k_SR)**：
  - k₀（kPa）：主动硬度幅值尺度；
  - k_ATP（s⁻¹）：收缩速率；
  - k_SR（s⁻¹）：松弛速率。
- 被动本构、循环与瓣膜参数在所有受试者间固定；观测层面的被动硬度尺度在 SBI 之前按受试者单独标定。
- 合成观测模型：**E_sim,d(s;θ) = E_pass,d(s) + E_sim_act,d(s;θ)**，其中 E_pass,d(s) 由拉伸相关的被动观测模型与舒张末期标定预先计算并固定。

### 2.3 背景条件化的 SBI 流程

- **核心思想**：不估计单一最优参数，而是推断后验分布以量化不确定性、参数补偿与实用可辨识性；跨受试者汇总训练一个摊销推断模型，得到各受试者的专属后验。
- **特征化条件（summary operator）**：
  - 采用"可解释标量描述子 + 粗粒度轨迹重采样"的混合摘要；
  - S(·): 曲线 → x = S(E) ∈ R⁴⁶，含 16 个标量描述子（基线/峰值硬度、幅值、曲线下面积 AUC、收缩上升、峰值时刻、峰后松弛等）与 30 个均匀重采样的轨迹值；
  - 预实验消融显示仅用标量摘要会退化后验预测性能。
- **观测噪声模型（特征空间）**：
  - 每个模拟特征向量加性高斯噪声 x^ε = x + ε，ε ~ N(0, Σ_x)；
  - Σ_x 为对角阵，仅在最大硬度、AUC、峰后 AUC、峰后衰减斜率、达峰时间五个特征上非零，原始特征单位标准差为 (1.0, 0.5, 0.5, 5.0, 0.03)；
  - 这些尺度先验设定、跨受试者固定，作为正则化观测超参数；重采样轨迹值不单独扰动（视为粗形状描述子而非逐点观测）。
- **汇总训练集**：各受试者参数样本 θ_d,n ~ p(θ) 经仿真、特征化、加噪后拼接；特征与背景用汇总训练集统计量标准化；条件向量 z = [x̃, c̃]，观测输入 z_obs,d = [x̃_obs,d, c̃_d]（标准化但不加噪）。
- **神经后验估计（NPE）**：
  - 用 sbi 工具箱的 NPE-C / SNPE-C 例程；密度估计器为默认的条件掩码自回归流（conditional MAF）：5 个变换、50 个隐藏特征、2 个自回归块、批大小 128、参数与条件输入标准化；
  - 训练目标为最大化条件对数似然：η* = argmax_η (1/|D_pool|) Σ log q_η(θ|z)；
  - 推断时对每个受试者从 q_η*(θ|z_obs,d) 采样，并将样本传入前向模型得到后验预测曲线。
- **先验设置**：独立有界对数高斯先验，对数中心 k₀ = 45 kPa、k_ATP = 5 s⁻¹、k_SR = 30 s⁻¹，对数空间标准差 (0.5, 0.6, 0.45)，硬边界 k₀ ∈ [10, 200] kPa、k_ATP ∈ [2, 30] s⁻¹、k_SR ∈ [2, 60] s⁻¹。
- **评估协议**：
  - **先验支撑诊断**：① 标准化条件向量满足 max_j |z_obs,d,j| ≤ 3（分布外检查）；② 从 5×10⁵ 候选抽样中至少有 1000 个后验样本落在先验边界内。两条同时满足才纳入定量后验分析；
  - **后验预测检验（PPC）**：从后验采样 θ，经前向仿真得 E_sim,d，评估后验能否复现观测 SWE 目标（注意：PPC 不等于参数唯一辨识）；
  - 指标：RMSE、NRMSE、R²、峰后 RMSE（针对 k_SR 相关的松弛动态）；90% 预测区间（PI）及其覆盖率；后验中位数、90% 可信区间（CI）、参数两两后验依赖；
  - **优化基线**：CMA-ES 逐受试者拟合，使用相同背景、被动基线与参数边界，最小化"归一化 MAE + 相关性失配 + 峰值失配"的组合目标；10 个随机种子（200–209）、种群 12、80 代、每受试者最多 9600 次仿真，取损失最低解作为诊断性点参考（非真值）。
